Walkthroughs

Illustrated, step-by-step pages for the things most games need. Each takes a few minutes and uses the demos in Samples/Demos/Scenes, so you can follow along.

  1. Your first save: the Start window, one object that remembers its state, F5 / F9 and the note in the Game view.
  2. World objects: doors and chests, pickups that stay collected, crates spawned during play, a switch wired to a gate, and scenes that remember.
  3. The save and load menu: adding it, opening it from your own pause menu, what the cards show, and making it yours with the Menu Style window.
  4. Game updates and migrations: keeping old saves loading when an update renames a value.
  5. Backups and recovery: a damaged save loaded from its backup, and the settings behind it.
  6. Use your own menu: a save menu of your own on the public API: list the slots, save with a picture, load and delete.
  7. Your own menu in UI Toolkit: the same in UI Toolkit, with a UXML layout, a USS style sheet and one script, plus Continue.

Before you start: the menu and the demos' text uses TextMesh Pro. If the Start window's strip shows No menu text yet, click Import (or answer Import when a demo scene asks); without TextMesh Pro's essential resources the panels and buttons are blank.

For how each part works, see the Guide and the Reference.
