Support

All In One Save Kit is made and supported by Romano Assets. This page says what support covers, how quickly you get an answer, how to report a problem, and how updates are released.

What support covers #

  • Bugs in the kit itself: something the kit does differently from what its documentation says, an error from the kit's own code, or a save that does not load the way it should.
  • Setting up and using the kit as documented: the Start window, the settings, Saveables, the save menu, the editor tools, game updates, co-op hooks and Steam Cloud.
  • The tested setups: Unity 2022.3 LTS, 6.3 LTS and 6.6, with the Built-in render pipeline, URP or HDRP, on Windows 10 and 11 (64-bit). Other platforms are not tested in 1.0; questions about them are welcome, but fixes are not promised.

Support does not cover reviewing or debugging your own game code, writing features for your game, or problems in other assets or packages. When the kit is part of a problem with another asset, we help find out where the problem is.

Response time #

Every new bug report, question and e-mail gets a first answer within 2 business days. A first answer may be a fix, a workaround, or a request for what is needed to reproduce the problem.

How to report a problem #

  1. Use Report a Bug. In Unity, choose Tools → All In One Save Kit → Report a Bug, or Report a bug in the Start window. It copies a report of your setup to the clipboard (kit, Unity and render pipeline versions, platform, your last three saves and loads, and what Diagnostics finds) and shows the address of the bug report form, with what it can fill already filled, to copy into your browser. The report holds no file paths beyond your save folder's name and none of your saved values.
  2. Add what happened, what you expected, and the shortest steps that show the problem, ideally in a new empty project or one of the kit's demo scenes.
  3. Paste the Console messages that start with [All In One Save Kit]. Each has a code, such as SK130, with its own entry in Troubleshooting.

Questions go to Discussions or the Romano Assets Discord. You can also e-mail marklromano@outlook.com.

Get help: Discord https://discord.gg/AmpBDxRAKu · bug tracker https://github.com/marklromano/RomanoAssetSupport · website https://marklromano.github.io/ · e-mail marklromano@outlook.com. With a question or a bug, please paste your system info: in Unity, Tools → All In One Save Kit → Start → Help and support → Copy system info.

Please report security issues, such as a way to read or change someone's saves that should not be possible, privately by e-mail rather than in a public issue.

Updates #

  • Bug fixes are released as patch versions (1.0.1, 1.0.2, ...) as soon as they are ready and tested.
  • New features come in minor versions (1.1, 1.2, ...).
  • Your players' saves keep loading. Every version of the kit reads saves written by earlier versions. A change that would need your save data upgraded is never made in a patch version, and the Changelog always says what changed and whether you need to do anything.
  • Updating is done through the Package Manager (My Assets). Your settings and registries live outside the kit's folder, so an update never overwrites them.
  • Known Issues lists problems that are known and not yet fixed, with workarounds.

Refunds #

Refunds for Asset Store purchases are handled by Unity under the Asset Store's own policy: see Unity's Asset Store refund policy. If something does not work for you, please report it first: most problems have a fix or a workaround.
