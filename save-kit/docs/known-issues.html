Known Issues

Problems in All In One Save Kit that are known and not yet fixed, with workarounds. Fixed issues move to the Changelog. To report something new, see Support.

Saving 10,000 objects takes slightly longer than targeted with the Mono backend #

Applies to: 1.0.0, Windows players built with the Mono scripting backend.

What happens: gathering the state of 10,000 changed Saveable objects on the main thread, the part of a save the player could notice as a short pause, takes a median of 66.6 ms in a Mono release build, against the kit's own target of 60 ms. Individual saves can take longer. With IL2CPP the same save takes 58.3 to 58.9 ms and meets the target. Writing the file happens on a background thread in both cases and is not part of this time.

Who notices: only games that save around 10,000 objects whose state changed since the last save, all at once. With 1,000 objects the same step takes about 6 to 7 ms on either backend.

Workarounds:

  • Build with IL2CPP (Project Settings → Player → Other Settings → Scripting Backend).
  • Save at moments where a short pause does not matter, such as a menu or a level change, rather than in the middle of action.
  • Untick what an object does not need to save. Each saver and field adds to the time.

The measurements, and how they were taken, are in Performance.
