Docs/Save Kit

All In One Save Kit documentation

Save and restore player progress, world objects and settings, with slots, autosaves, a finished save menu, backups and automatic recovery from damaged saves.

  • Unity 2022.3+
  • Built-in, URP & HDRP
  • No code needed
  • Full C# source
  • Version 1.0.0

Coming soon to the Asset Store.

Get started

Quick start: five minutes

  1. Import the package from the Asset Store. Everything lands in Assets/AllInOneSaveKit/, and the Start window opens.
  2. In the Start window, click Fix on any item of the setup check that isn't ticked.
  3. Click Make objects remember, pick the objects that should keep their state, and tick what each one keeps.
  4. Press Play, then F5 to save and F9 to load. A note in the Game view says what was saved and what came back.
