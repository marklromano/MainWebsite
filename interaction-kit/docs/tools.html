Tools

Scene Overview #

Tools > All In One Interaction Kit > Scene Overview lists every interactive object in the open scenes: what it is (door, drawer, lock...), its state (live in Play mode, with its prompt), and its problems. Click a name to select the object. Only problems hides the rest; the search box filters by name or type.

Checking for problems #

The Scene Overview (and Tools > All In One Interaction Kit > Check Scene For Problems) finds common setup mistakes, with a one-click fix where there is one:

Problem Fix
Does nothing (no part like a Hinge or Switch) Add one, or use the Setup Wizard
No collider (players can't look at it) Adds a box collider around what it shows (2D for sprites)
Colliders on the Ignore Raycast layer Moves them to Default
Max Distance under half a metre Sets 2.5 m
Empty prompt Uses the object's name
No Save Id, or a Save Id used twice (copied objects) Adds one, or gives a new one
No Interactor in the scene (add one to your player)
No prompt in the scene Adds one

Fix all applies every fix for errors and warnings at once (each can be undone).

Making many prefabs interactive #

Select prefabs in the Project window (as many as you like), then Assets > All In One Interaction Kit > Make Selected Prefabs Interactive, or Convert all selected prefabs in the Setup Wizard. Models with doors, drawers and lids as child objects get each part set up; single objects are recognised by name (switch, button, lever, plate, crate, note, keypad, fuse box, door). Your originals are never changed: a new prefab is saved next to each. Anything it can't recognise is listed so you can set it up in the wizard.

Gizmos #

Select an Interactable to see how close players must be (its bounds grown by Max Distance). Hinges show their arc, ladders their climb and exits, elevators their stops.
