Upgrading

How to update the kit, and what changed in each version that you may need to act on.

How to update #

  1. Back up your project (or commit it to version control).
  2. Import the new version from the Package Manager (My Assets) over the old one.
  3. Your own prefabs, scenes and settings are not touched: the kit never edits your files, and the Setup Wizard's prefabs keep working because component names and settings are never renamed.
