Code and your own UI

Nothing here is needed for the main jobs. Everything is in the RomanoAssets.WaypointKit namespace.

Waypoints from code #

var w = gameObject.AddComponent<Waypoint>();
w.Label = "Old Mill";
w.Icon = WaypointIcon.Flag;
w.IsObjective = true;
w.Reached += wp => Debug.Log("Reached " + wp.Label);

w.Hide();   // switch off (markers disappear)
w.Show();   // switch on

A waypoint with no object of yours (a quest coordinate):

var drop = Waypoint.CreateAt(new Vector3(120f, 0f, 40f), "Drop Zone", WaypointIcon.Pin);
drop.Position = newPosition;
drop.SetAsCurrentObjective();   // the only objective now
drop.Remove();                  // gone

Useful: WaypointRegistry.Waypoints, WaypointRegistry.CurrentObjective, WaypointRegistry.FindById(id), WaypointRegistry.FindAll(label, list), WaypointRegistry.SetGroupVisible(group, visible), the Added and Removed events, and ResetReached() for pooled objects.

The HUD from code #

var hud = WaypointHud.Main;
hud.UsePreset(WaypointPreset.Tactical);
hud.ShowRadar = false;
hud.Units = WaypointUnits.Feet;
hud.RadarZoom = 2f;            // closer
hud.SetCamera(vehicleCamera);  // camera switches (null = Main Camera)
hud.SetPlayer(newCharacter);   // null = the object tagged Player
hud.SetVisible(false);         // cutscenes and menus
float ms = hud.LastDrawMilliseconds; // the HUD's own cost last frame
hud.Style.Marker.iconSize = 40f;
hud.Style.Touch();             // after changing style fields from code

Your own UI #

Each frame the HUD works out, for every waypoint: distance, height, whether it's on screen, its screen position and edge angle, its compass bearing and its radar point. Read it after the Drawn event:

hud.Drawn += h =>
{
    if (h.TryGetView(myWaypoint, out var v) && !v.IsOnScreen)
        myArrow.SetPositionAndAngle(v.ScreenPosition, v.ScreenAngle);
};

Switch off the parts you replace (ShowMarkers, ShowEdgeArrows, ShowCompass, ShowRadar) and keep the rest. WaypointView.Reason says why a waypoint isn't drawn.

Words for other languages #

  • Names: Waypoint.Label (set it from your localisation system).
  • Units: DistanceText.MetreSuffix, KilometreSuffix, FootSuffix, MileSuffix.
  • Compass letters: the style's Compass > Direction Words.

Saving #

WaypointSave.Capture() and WaypointSave.Restore(text); see Objective trails, events and saving.

Explaining #

WaypointDiagnostics.Explain(waypoint) returns the same plain sentence as the debugger.
