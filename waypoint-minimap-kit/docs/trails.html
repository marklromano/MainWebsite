Objective trails, events and saving

A trail of objectives #

  1. Add a Waypoint to each step (bridge, tower, canoe, camp).
  2. On each one set Reach Radius (for example 6), When Reached to Switch To Next, and Next to the following step.
  3. Tick Current objective on the first, and switch the Waypoint components of the others off.

When the player reaches a step, it switches off and the next one switches on and becomes the objective. The last one can use Switch Off. The Showcase demo is built this way.

Events #

Every Waypoint has On Reached and On Left (UnityEvents in the inspector) and the C# events Reached and Left. Use them to open doors, start dialogue, give rewards or update your quest log.

Groups #

Give waypoints a Group ("Shops", "Enemies") and show or hide them together:

WaypointRegistry.SetGroupVisible("Shops", false);

Saving #

WaypointSave remembers which waypoints are on, reached and the objective, as a short text for your own save system:

string text = WaypointSave.Capture();   // when saving
WaypointSave.Restore(text);             // after the scene loads

Each Waypoint has a Save Id, filled in for you. If you duplicate a waypoint, the scene check offers a new id.
