Why Can't I See It? and the scene check

The window #

Tools > All In One Waypoint & Minimap Kit > Why Can't I See It? (Scene Overview)

Scene check lists setup problems with a one-click fix where there is one:

Problem Fix
No Waypoint HUD in the scene Add HUD
The HUD has no camera Use the scene's camera
A 2D camera with a 3D (XZ) HUD Use 2D (XY)
Two HUDs drawing for one camera (select them)
Custom icon with no sprite Use the Objective icon
Switch To Next with no Next, or Next pointing to itself (select it)
Hide Within larger than Show Within, so it never shows Clear Hide Within
Two waypoints sharing a save id New id
More than one Waypoint Map, or a map with no picture Bake map

Every waypoint lists each waypoint with where it shows ("Shown as an edge arrow, 63 m away. Also on the compass and radar.") or why it doesn't ("Hidden: the player is closer than Hide Within (3 m)."). Click one to select it. It updates live while playing.

The same sentence shows at the top of each Waypoint's inspector.

In the game: the debug overlay #

Add Waypoint Debug Overlay to the HUD's object and press F8 while playing for the same list on screen (the key can be changed). It makes text only while it is open. Remove it before shipping if players shouldn't find it.

The reasons #

Reason Meaning
No camera Set the HUD's View Camera, or tag your camera MainCamera.
Group hidden WaypointRegistry.SetGroupVisible(group, false) was called.
Too close / too far Hide Within or Show Within.
Reached When Reached is Hide While Near and the player is inside the reach radius.
Markers off / edge arrows off Switched off on the waypoint, the HUD or the style.
Screen full More important or nearer waypoints took the places. Raise its Priority or the style's Max Count.
