All In One Waypoint & Minimap Kit documentation

Show players where to go: objective markers, edge arrows with distance, a compass bar, a minimap and a full-screen map, with a one-click map maker, fog of war and region discovery.

  • Unity 6000.0+
  • Built-in, URP & HDRP
  • No code needed
  • Full C# source
  • Version 1.0.0
Get started

Quick start: five minutes

  1. Import the package. Everything lands in Assets/AllInOneWaypointKit/.
  2. Open Tools > All In One Waypoint & Minimap Kit > Setup Wizard. It adds the HUD, finds your player and camera, and picks a look.
  3. Add a Waypoint component to any object and pick an icon.
  4. Press Play. The waypoint shows on screen, at the screen edge, on the compass and on the minimap; M opens the map.
