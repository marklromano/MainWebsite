Upgrading

1.0.0 #

The first release. Nothing to do.

How updates work #

  • Your own styles, maps and other data live in Assets/RareGeometryData/Bearing, which updates never touch.
  • Public names, menu items and saved fields are kept between versions; anything that changes is listed here with what to do.
  • To update: import the new version over the old one. You can move or rename Bearing's own folder (Assets/RareGeometry/Bearing); it still works. Keep the shared Core and EditorUI folders where they are.
