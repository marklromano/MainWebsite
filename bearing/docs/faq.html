Docs/Bearing/Reference

Questions people ask

Does it need code? No. Everything is set up in the inspector, the Setup Wizard and the Chart Table. Code is there when you want it (see Code and your own UI).

Which Unity versions and render pipelines? Unity 6 (6000.0 and newer), Built-in, URP and HDRP. The HUD is drawn with UI Toolkit, so it looks the same in every pipeline; nothing needs a shader of yours.

Does it work with my character controller and camera? Yes. The HUD only needs a camera to draw for and an object to measure distances from. Pick them in the Setup Wizard; neither needs a tag. A camera your game makes while playing is found through the Main Camera.

Old Input Manager or the Input System? Both. With the Input System package installed, gamepads control the map.

Will a big level slow it down? It draws without making garbage each frame, checks walls a few times a second at most, and the Clean map is drawn once in the editor, not while playing.

The map shows something that isn't in my level. The Clean map traces what is seen from above. Run Check Map Against World (Tools > Bearing) to see where they differ, then tell it what an object is (Draw as) or leave it off.

A place doesn't show. Open Why Can't I See It?: it lists every place and says why it is or isn't showing.

Can players place their own markers? Yes: pins and stamps with icon, colour, name and note, saved with the game. What they may do is a Player Map Permissions asset.

Multiplayer? Each HUD draws for its own player (split screen works out of the box). Sharing markers between players works through any network; a Netcode for GameObjects adapter is included and turns on when that package is installed.

Another language? Every word goes through one text table, with a Unity Localization bridge.

Does it work with the other Rare Geometry products? Bearing works alone. With Snapbuild, Interactra, Responsive FX or Shipready in the same project, their places, saves and settings join in by themselves (Help shows which are installed).

Is my data safe when I update? Your maps, styles and options live in Assets/RareGeometryData/Bearing, which updates never touch. See Upgrading.
