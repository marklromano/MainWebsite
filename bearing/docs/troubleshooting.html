Troubleshooting

First open Why Can't I See It? (Tools > Bearing). It explains most problems and fixes many in one click.

Problem Answer
Nothing shows at all The scene needs a Waypoint HUD with a camera. The scene check adds one.
Nothing shows in the Game view before Play Turn on Preview In Edit Mode on the HUD.
A marker shows twice Two HUDs draw for the same camera; the scene check finds them.
A marker disappears when I get close Hide Within is set, or When Reached is Hide While Near.
A marker shows in the wrong place Turn Mark Above Object off and use Offset, or call RefreshTop() after the model changes size.
The compass points the wrong way Set North Angle on the HUD.
The radar is upside down in my 2D game Set the HUD's Plane to XY.
The map picture is grey or wrong Bake again in the editor with the scene open (the bake needs a graphics device). Leave the player out with Bake Layers.
The HUD is under my other UI Raise Sorting Order on the HUD.
Text looks different from my UI Set your font in the style's Text section.
Arrows overlap my own UI Increase Edge Arrows > Margin, or move the radar to another corner.

Still stuck? See Support.
