Make Buildable

Tools > All In One Runtime Building Kit > Make Buildable turns a model or prefab into a Piece Definition: an asset that holds everything the kit needs to build it. The model itself is never modified.

Steps #

  1. Model: drag a prefab or model from the Project window. The kit measures its mesh renderers (LOD 0 only) and shows the size in metres.
    • Size check: if the size is unusual for the preset (a 4.7 m chair, a 13 m wall), a warning says so and offers Use Scale × 0.1 (or whatever factor fits). That sets the piece's Scale; your model is not changed. You can also fix the model's own import Scale Factor and drop it in again.
    • Collider: if the model has no colliders, choose Box (one box around the footprint) or Mesh (follows the model, so windows and doorways stay open). Placement checks always use the footprint box. Mesh needs Read/Write on in the model's import settings, because the collider is made in the game: the window warns and turns it on with one click (the model file isn't changed). Without it, a build uses boxes instead.

  2. Preset: decides the sockets (snap points) and the placement settings.

    • Foundation: 4 side sockets (join other foundations) and 4 top-edge sockets (hold walls).
    • Wall: bottom, top and 2 side sockets. It faces along its thinnest side.
    • Floor: side sockets, bottom-edge sockets that rest on walls, top-edge sockets for walls above.
    • Furniture: no sockets; stands on floors and on top of tables and shelves, tilted to match them, and must be fully supported.
    • Wall Mounted: no sockets; hangs on walls with its back against them (pictures, wall shelves, lamps), and must be fully supported. Suggested for thin, small, upright models.

    The suggestion comes from the model's shape at its placed size.

  3. Name and Category: the name (tidied from the file name, e.g. "floorFull" becomes "Floor Full") appears in reasons such as "Overlaps Wall_03".

  4. Save to: your data folder by default (Assets/AllInOneRuntimeBuildingKitData/Pieces). An existing file is never overwritten: a numbered name is used instead. If a piece for the same model already exists, you're asked first.
  5. Show in Scene (optional): shows the model in the Scene view with its footprint box and sockets. Drag the box handles; click a socket sphere to select it, W moves it, E rotates it. The blue arrow points out of the piece, the green line is the socket's up.
  6. Create Piece, then Test in Play Mode.

The Piece Definition #

Select it to edit it in the Inspector: Identity (name, category, icon, ID), Source (the model and its Scale), Footprint, Placement (modes, grid cell and rotation step, goes on and also goes on, only on categories or tag, align to surface, needs support, max slope, max distance), Turning (own rotation step, random turn, turns on walls, tilt), Rows, Areas and Limits, Sockets (each with its Join: flush or centred; with Apply Preset…), Looks (variants), the piece's own look and sound, and Check and Test. The presets switch rows on for walls, and rows and areas for foundations and floors.

The ID never changes by itself. Saves and multiplayer use it, never the name. Duplicating the asset copies the ID: the kit warns in the Console, and Pieces offers Give this one a new ID.

Pieces tab #

Pieces lists every piece with its problems and a one-click Fix for each; see The kit window.
