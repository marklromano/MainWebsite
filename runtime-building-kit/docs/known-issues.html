Known Issues

Version 1.0.0.

  • While a row, an area or a blueprint is being dragged, the preview checks every piece of it (again only when the aim or the world changes). On a very large base, very large rows can take a few milliseconds a frame while dragging. Max Batch (64) caps them.
  • A blueprint keeps pieces' looks, turn and socket links; it doesn't keep a piece's owner or saved contents of your own.
  • HDRP needs the project in Linear colour space (HDRP's own setup does this); in Gamma nothing is lit.
  • With the old Input Manager, the samples read gamepad buttons only; gamepad sticks and the d-pad (build menu) need the Input System package. Changing keys in the build menu needs it too.
