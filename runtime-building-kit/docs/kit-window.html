Docs/Runtime Building Kit/Using the kit

The kit window

Tools > All In One Runtime Building Kit > Open opens one window with five tabs. Every main job is in it; you never need the Project window or code. Hover any control for a tooltip.

Tab For
Home The quick start, a short tour of the window, and the documentation.
Make Buildable Turning your own model into a build piece. See Make Buildable.
Pieces Every build piece in the project, its problems, and one-click fixes.
Settings Where your data is saved and what new pieces start with.
Help Version, documentation, support links and Copy support info.

Home #

Three quick-start steps, each with a button that takes you to the right place: Open Sample Scene (the First Slice: press Play and build), Make Buildable and Pieces. Take the Tour walks through every tab in a few clicks; Documentation shows these pages in the Project window. Tick Show this window when the project opens if you want it on startup (off by default).

Pieces #

Lists every Piece Definition in the project with its category, number of sockets and problems. Problems Only hides the healthy ones; Rescan looks again. Select a piece for Select Asset (edit it in the Inspector), Edit in Scene (drag its footprint and sockets with handles) and Test in Play Mode (a throwaway test scene with the piece selected).

Each problem has a Fix button that solves it in one step (one Undo):

Problem Fix
No ID Assign ID
Shares its ID with another piece (a duplicated asset) Give this one a new ID
No prefab or model Select (then drag one into Prefab or Model in the Inspector)
Footprint empty or tiny Measure from prefab
No placement mode allowed Allow Socket + Free
Socket placement only, but no sockets Allow free placement (or apply a preset)
Socket without a type Remove socket
Socket without an ID, or two sockets with the same ID Generate socket ID / Rename socket
Grid on, but the piece hangs on walls or ceilings Turn the grid off
A cost line without a resource Remove empty lines
Upgrades To leads back to itself Clear Upgrades To
Mesh collider, but the model's Read/Write is off (a build couldn't make the collider) Turn on Read/Write

The Console also warns when a duplicated Piece Definition shares an ID, as soon as it is imported.

Settings #

Setting What it does
Data Folder Where new Piece Definitions and other data you make are saved (Assets/AllInOneRuntimeBuildingKitData by default). Kept outside the kit's folder so updates never touch it. Change… picks another folder inside Assets.
Max Slope (°) The steepest surface new pieces may be placed on. 90 turns the check off.
Max Distance (m) The furthest a new piece may be placed from the player. 0 turns the check off.
Show Home On Startup Opens the window on Home whenever the project opens.

These are defaults for new pieces; each piece keeps its own values in its Piece Definition. The settings are saved in ProjectSettings, so they go into version control with your project.

Help #

The kit's version, the offline and online documentation, and the support links as text you can select and copy (Discord, bug tracker, website, email). The kit never opens a website by itself. Copy support info copies the kit version, Unity version, render pipeline, platform and input system: paste it into a bug report.
