Docs/Footstep Kit/Features

When steps happen

Steps come from on Surface Footsteps decides when a step plays.

Automatic (default) #

A step every stride while the character moves on the ground. The stride is set per movement in the profile (walk 0.75 m, run 1.15 m, sprint 1.4 m, crouch 0.55 m in Realistic) and the movement comes from the speed (run from 3.5 m/s, sprint from 6.5 m/s). Works with every controller, NPCs moved by any script, and remote players, because it only watches movement. Jumps and landings are detected the same way: leaving the ground upwards faster than Jump Speed is a jump, touching down after Min Air Time is a landing, louder for a faster fall.

Animation Events #

For exact timing with animated characters. Add events to your walk and run clips with one of these function names: Footstep, FootstepLeft, FootstepRight, FootL, FootR, OnFootstep (the name Unity's Starter Assets and many animation packs already use), and OnLand for landings.

Unity sends animation events to the Animator's own object. When Surface Footsteps sits on a parent (usual), add Footstep Animation Events to the Animator's object; the Setup Wizard and the debugger's fix button do it for you. In a blend tree or crossfade every clip fires its events. An event from a clip with half the weight or more plays at once; when no clip has that much, only the strongest event of that frame plays (down to Min Event Weight, 0.2), so steps are never doubled or lost. Jumps and landings are still detected from movement.

Foot Bones #

For animated characters without events: the kit watches each foot bone and plays a step when it comes down. It learns how high each foot lifts, so it works with any rig and scale. Set Left Foot and Right Foot (the wizard finds them on humanoids).

Manual #

Only when your code calls Step(), Step(Foot, FootstepMovement), Jump() or Land(fallSpeed). Use it for cutscenes, ladders or anything with its own timing.

Never machine-gun steps #

Min Step Interval (0.12 s in Realistic) is the shortest time between two steps, whatever triggers them. Skipped steps show "Too soon" in the debugger.
