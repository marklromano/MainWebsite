Upgrading

Updating the kit #

  1. Back up your project (or commit it).
  2. Import the new version from the Package Manager (My Assets).
  3. Read the changelog section for your version.

Your own content lives outside the kit's folder (Assets/FootstepKitData for libraries, surfaces and profiles made by the tools), so an update never overwrites it. If you changed the sample library or surfaces directly, make your own copy first (Setup Wizard > Make my own copy): updates replace the sample files.

The kit's folder can be moved or renamed in your project; tools find their files wherever they are.

Coming from another footstep tool #

  • Your existing physics materials or tags per ground can be mapped once in the Surface Library.
  • Animation events named OnFootstep (Starter Assets and many packs) already work with Animation Events.
  • Remove or silence the other tool's audio so you don't hear both (the wizard offers this for Starter Assets).
