Why No Footstep? and Scene Overview

Why No Footstep? (window) #

Tools > All In One Surface Footstep Kit > Why No Footstep? Pick a character (or select it in the Hierarchy).

Setup check lists every problem it finds, most serious first, each with a fix button where one exists:

Problem One-click fix
No Surface Library Use the sample library (or yours)
The library has no default surface Set a default
A surface has no Walk sounds Select the surface
The ground is on a layer Ground Layers leaves out ("Floor is on layer Environment") Include that layer
The feet are below or above the ground ("feet are 0.90 m below the ground") Put the feet on the ground
The ground matches no surface (plays the default) Map its material to a surface you pick
Animation Events, but the Animator is on a child without the relay Add the relay
Foot Bones, but no bones set Find foot bones (humanoids) or use Automatic
No Audio Listener in the scene Add one to the camera
The listener is beyond the profile's Max Distance Select
Footprints on but no footprint picture Select the profile

Live (Play Mode) shows whether the character is on the ground, its speed, walk / run / sprint / crouch, how far through the stride it is, and what is under the feet. Below it, every step attempt, newest first: what played, on which surface and why that surface ("Walk on Grass from terrain layer Lawn", "Walk on Stone (the default: nothing matched)"), and for any step that didn't play, the reason: Too soon, No ground, No surface, No sounds, Muted, No library, Switched off. Click a step to select the ground it touched.

In-game panel #

In-game panel adds a Footstep Debug Overlay to the scene: the same live view inside the Game view and in development builds. F4 shows and hides it (change the key, the corner and the rows in its inspector). With Development Only on (the default) it never shows in a release build.

Scene View #

Select a character to see its ground check (blue) and the last steps: a line and dot per step in the surface's colour, red for a step that didn't play.

Scene Overview #

Tools > All In One Surface Footstep Kit > Scene Overview shows the whole scene:

  • Characters: each one with its library, profile and any problems (with fixes).
  • Surfaces: every material, terrain layer and tile, what it plays now and why, with a picker to map it.
  • Zones: every zone, its surface and mode; adds a shape to a zone without one.
