Interactra documentation

Make anything interactive, then let players build: doors, switches, keys and elevators from your own prefabs, runtime building with ghosts, blueprints and wiring, and one save for all of it.

  • Unity 6000.0+
  • Built-in, URP & HDRP
  • Both input systems
  • Full C# source
  • Version 1.0.0

Coming soon to the Asset Store.

Get started

Quick start: five minutes

  1. Import the package. Interactra lands in Assets/RareGeometry/Interactra/.
  2. Open Tools > Interactra > Open Demo and play the Buildable Puzzle House.
  3. Open Tools > Interactra > Setup Wizard, pick your prefab and what it does.
  4. Open Tools > Interactra > Workbench to set up building pieces, wiring and rules.
