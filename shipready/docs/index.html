Shipready documentation

Menus, settings, saves, tutorials and playtest tools in one connected package: the title screen, the settings players expect, saves that survive crashes, first-time tours and bug reports with steps.

  • Unity 6000.0.85f1+
  • Built-in, URP & HDRP
  • Unity UI + TextMesh Pro
  • Full C# source
  • Version 1.0.0

Coming soon to the Asset Store.

Get started

Quick start: five minutes

  1. Import the package. Everything lands in Assets/RareGeometry/Shipready/. Try Samples/LighthouseBay/Showcase_LighthouseBay.unity and press Play.
  2. Open Tools > Shipready > Launch Desk and pick your game's starting point.
  3. Click Connect My Game. Every step is shown before anything changes.
  4. Press Play: the title screen opens, settings apply and the game saves and continues.
