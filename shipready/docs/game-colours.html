Game colours

Some things in a game are told apart by colour: enemies and allies, loot, danger zones, the path to follow. For players with colour blindness a filter over the whole picture rarely helps. What helps is letting them pick those colours themselves, from a palette whose colours stay apart for every kind of colour vision.

Add one #

  1. Create > Shipready > Menus > Accessibility > Game Color.
  2. Give it an id such as colors.enemy and a name players see ("Enemies").
  3. Keep the starting palette (eight colours that stay apart with the common kinds of colour blindness) or edit it. Set Default Value to the colour your game uses today.
  4. Add the asset to your settings profile, in the Accessibility category.

The settings menu shows the colour's name with a bar in that colour under it.

Use it #

Without code: add a Game Color Target to the object (Add Component > Shipready > Menus > Game Color Target) and type the setting's id. It colours what it finds on the object: a sprite, a mesh or skinned renderer (through a property block, so materials are not copied), a line or trail, a light, a particle system, or a canvas image or text. It follows the player's choice at once.

Option Meaning
Player Which local player's choice to use (0 is player one)
Keep Alpha Keep the object's own alpha and take only the colour
Emission Also set the material's emission colour, multiplied by this
Include Children Also colour the same kinds of things on child objects

From code:

// The colour the player chose, or the colour you pass when the game has no such setting.
marker.color = GameColors.Get("colors.enemy", Color.red);

// Follow a change.
GameColors.Changed += id => { if (id == "colors.enemy") Recolour(); };

// Split screen: each player's own choice.
Color forPlayerTwo = GameColors.Get(1, "colors.enemy", Color.red);

The Steam "Color Alternatives" tag #

The Readiness tab lists how many game colour settings players have. The tag is true once every important signal that used colour alone is one of them, or is backed by a shape, an icon or a word. Walk through the game and check.
