Docs/Shipready/Menus and settings

Settings reference

Every setting in the default profile, by tab. Tier: Auto = Shipready applies it; Connect = it drives something in your scene (a component or your callback); Read = Shipready stores it and your code reads it. Ids are what your code uses (SettingsRuntime.Current.GetValue("id")) and what the settings file stores. Settings that need a package or a render pipeline are hidden where they can't work.

This page is generated from the shipped settings.

Display #

Setting Id Tier Default Values What it does
Resolution display.resolution Auto the game's launch value what the player's screen supports Screen resolution.
Refresh Rate display.refresh-rate Auto the game's launch value what the player's screen supports Refresh rate for the chosen resolution (exclusive full screen).
Window Mode display.window-mode Auto the game's launch value Fullscreen, Borderless, Windowed Full screen, borderless or windowed.
Monitor display.monitor Auto the game's launch value what the player's screen supports Which monitor shows the game. Only shown when more than one is connected.
VSync display.vsync Auto the game's launch value On, Off Syncs frames to the monitor to prevent tearing. Off can lower input latency.
Frame Rate Limit display.frame-rate-cap Auto the game's launch value Unlimited, 30 FPS, 60 FPS, 90 FPS, 120 FPS, 144 FPS, 165 FPS, 240 FPS Upper limit for frames per second (when VSync is off).
FPS Counter display.fps-counter Auto Off On, Off Shows frames per second in the top right corner.
Screen Edges display.screen-edges Auto 0% 0% to 10% Moves the menus away from the screen edges, for TVs that cut them off.
Adjust Screen Edges display.screen-edges-page Read Adjust the screen edges for a TV that cuts off part of the picture.

Post Anti-aliasing graphics.post-antialiasing Auto Off Off, FXAA, SMAA, TAA Edge smoothing applied after rendering. TAA is smoothest, FXAA is cheapest.
