Finishing a Step

Add one or more rules to a step's object (Add Component > Shipready > Rules). The step finishes when any rule is done, or when all are (the step's Finish When). A step with no rule finishes with the Next button. Every rule runs on real time and tells the debugger what it is waiting for.

Rule Finishes when Notes
Click Target Rule the player clicks or taps the step's target uGUI, UI Toolkit, world objects and screen areas. Set how many clicks.
Key Rule one of its keys is pressed (or held for a time) Both input systems.
Input Action Rule an Input System action is performed Gamepads and rebinding included. Needs the Input System package.
Gesture Rule a tap, long press, swipe (any way or one way), drag or pinch Mouse or touch; optionally only on the target.
Move Distance Rule the player has moved a distance Ignores teleports. Uses the object tagged Player when Subject is empty.
Look At Rule the camera (or any object) faces something for a moment Uses the step's world target when Look Target is empty.
Area Rule the player is inside an area A 3D collider, a 2D collider, or a distance from a point.
Timer Rule some seconds have passed Real time: runs while paused.
Counter Rule something happened a number of times Call Add from a UnityEvent ("collect 3 coins").
Condition Rule a field or property of any component reaches a value bool, int, float, double, string, enum. No code.
Event Rule something calls its Mark Done Drag it into any UnityEvent, or call it from one line of code.
Object State Rule an object reaches a state another product reports (a door becomes Open) Put a Stable Id on the object and type the state. Works with Interactra and any product or code that reports object states; needs nothing when none is in the project.
Visual Scripting Event Rule a graph triggers a Custom Event with its name Needs the Visual Scripting package.

Tips #

  • "Press Space or tap Jump": add a Key Rule and a Click Target Rule, Finish When Any Rule.
  • "Collect 3 coins": a Counter Rule, and each coin's pickup event calls the rule's Add.
  • "If the player already knows this, skip it": tick the step's Skip If Already Done. A Condition Rule or a Counter Rule with Count Before Step Starts is done straight away when the player already did it.
  • Your own rule: derive from CompletionRule (see Extending).
