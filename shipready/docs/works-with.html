Working with other products

Shipready needs no other product. This page is about what happens when there are others, and about games that keep part of what they already have.

Other Rare Geometry products #

When another Rare Geometry product is in the project, nothing has to be set up:

  • One save. Whatever the other product saves (map discoveries, built pieces, object states) joins the player's save slot and comes back when that slot is loaded. A save the product made on its own before Shipready arrived still loads.
  • One set of accessibility choices. The other product follows the player's settings: reduced motion, camera shake and flash strength, text size, high contrast, colour-blind mode, hold or toggle, subtitles.
  • One readiness report. The other product's own diagnostics show on the Readiness tab.
  • Object states in tutorials. A tutorial step can wait for an object to reach a state another product reports (a door becomes Open): add an Object State Rule to the step.

Remove Shipready and the other products go back to saving by themselves. Nothing of theirs is deleted.

The Start tab of the Launch Desk lists the products it found.

Keeping your own save system #

You can use Shipready's menus and settings with the save system you already have (your own, or another asset's).

  1. Add an Own Save Bridge to the object with the Menu Root (Add Component > Shipready > Menus > Own Save Bridge).
  2. Wire its four events to your save code:
Event When Do
On Continue Continue was pressed Load the newest save and enter the game
On Open Load Load Game was pressed Open your load screen
On Open Save Save Game was pressed in the pause menu Open your save screen, or save at once
On Close Back was pressed while your screen was open Close it
  1. Tell it whether a save exists, so Continue and Load Game show only when there is something to load: call SetHasSave(true) from your save system's events, or set a check from code:
var bridge = GetComponent<OwnSaveBridge>();
bridge.HasSaveCheck = () => MySaves.Any();
bridge.IsOpenCheck = () => myLoadScreen.activeSelf;

While the component is enabled it takes the place of Shipready's own save connection. Disable it to hand the menus back.

Keeping your own menus #

Choose Keep my own menus on the Launch Desk's Start tab. Only settings and saves are set up. From your own screens:

SettingsController settings = SettingsRuntime.Current;
settings.SetPendingFloat("audio.master-volume", 0.5f);
settings.Apply();

SaveKit.Save(1);          // slot 1
SaveKit.Load(1);

Settings/Documentation/ExtendingAPI.md and Save/Documentation/Reference.md have the full lists.

Narration (text to speech) #

While the player's Narration setting is on, the menus send every line a screen reader would speak (the focused button, a setting's name, value and help, each screen's title). Shipready does not speak by itself. Connect a voice:

public sealed class MyVoice : INarrationVoice
{
    public void Say(string text, bool interrupt) { /* your platform's text to speech */ }
    public void Stop() { }
}

MenuNarration.Voice = new MyVoice();

To check the wording first, add a Narration Caption to any object: it shows each line on screen.
