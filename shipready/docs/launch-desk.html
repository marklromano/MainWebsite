Launch Desk

Tools > Shipready > Launch Desk is the main window. It has four tabs and a question mark.

Start #

Connect my game sets Shipready up in the open project. Choose a path (New game, Existing game, Keep my own menus), read the plan, press Connect.

  • The plan lists each step with a plus (will be done), a tick (already done) or a warning (cannot be done yet, with the reason, for example an unsaved scene).
  • Look again reads the project again after you changed something. It changes nothing.
  • Steps that touch the scene are one undo step. Steps that make assets put them in Assets/RareGeometryData/Shipready.
  • Each part of Shipready adds its own steps. If you deleted the Tutorials or Playtest folder, their steps are gone too.

Under it: Inspect my project (the same as the Readiness tab), what is in the box with a button for each part's own window, and the other Rare Geometry products Shipready found in the project.

Player Options #

One asset decides what players see and may change. See Player Options.

Look #

One asset gives every player screen the same colours, fonts and rounding. See Game Look.

Readiness #

The Ship Readiness Checker. See Ship Readiness Checker.

The question mark #

Help: the quick start, the manual's folder, the support addresses as text to copy, and Copy system info.

The other windows #

Menu Window What it is for
Tools > Shipready > Menus > Menu Builder Menu Builder Screens, layout, themes, the settings list, a check of the front end
Tools > Shipready > Saves > Start Saves Status of the save setup and the demos
Tools > Shipready > Saves > Setup Wizard Save Setup Slots, autosave, backups, encryption, the save menu
Tools > Shipready > Saves > Menu Style Save Menu Style The save menu's look and layout
Tools > Shipready > Saves > Save Inspector Save Inspector Read and edit save files

Tools > Shipready > Playtest > Report Inbox Report Inbox Bug reports from testers
Tools > Shipready > Playtest > Setup Wizard Bug Report Setup The form, the keys, where reports go
Tools > Shipready > Tutorials > Scene Overview Tutorial Overview Every tutorial in the open scenes
Tools > Shipready > Tutorials > Why Is This Step Waiting Tutorial Debugger What a running step waits for

Every window opens with the same header: the product name, the window's name, and the sailboat on its tab.
