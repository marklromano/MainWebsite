Make it yours

Everything players see can be changed, and so can what players are allowed to change. This page lists each thing and where it is. Your changes live in Assets/RareGeometryData/Shipready; updates of Shipready never touch that folder.

The big switches #

What Where
Colours, fonts, text size and corner rounding of every screen at once Launch Desk > Look (Game Look)
Which settings players see and may change, with limits and starting values Launch Desk > Player Options (Player Options)
What players may do with saves; skipping tutorials; tester tools per build Launch Desk > Player Options
Who a setting belongs to (device, each player, a save, this session) The setting's asset, Scope (Per-player settings)
The colours your game uses to tell things apart Game Color settings (Game colours)

Menus and settings #

What players see Where you change it
Which screens exist (title, main menu, pause, settings, loading, credits, extras) and their buttons Menu Builder > Setup
The layout (centred, side column, bottom bar, full-screen tabs) Menu Builder > Setup, or Tools > Shipready > Menus > Layout
The theme: fonts, sizes, colours, images, button shape, choice and switch style, tab line, scroll bar Menu Builder > Theme, or the theme asset. Three themes ship (Clean, Tactical, Storybook); copy one to start
Backgrounds per screen (colour, image, video, blur of the game) and how see-through panels are The theme asset, or the Menu Root for one front end
Screen transitions (fade, slide, scale, none), their length and easing; focus scale and frame The theme asset. Reduce Motion turns movement off for the player
Menu sounds (move, select, back, open, slider, switch, error) The theme asset
Where notices and prompts appear and how much they show (full text, short text, icon) The theme asset or the Menu Root
Logo, game name, version line, credits The Menu Root (branding) and the Credits screen
Every word, and other languages The text table (Settings/Documentation/Localization.md)
The settings list: which settings, their order, categories, names and help lines The settings profile (Menu Builder > Settings)
Accessibility presets (easier to read, less motion, hearing support, easier controls) The preset assets in your profile
What the first launch asks before the logos (accessibility, display, sound, controls) The Startup Sequence on the front end
Button pictures for keyboard, Xbox, PlayStation and Switch The prompt set on the front end (Settings/Documentation/ControlsAndRebinding.md)
The voice that reads menus aloud MenuNarration.Voice (Working with other products)
The keyboard a controller player types with TextEntry.Provider (your platform's keyboard), or the built-in one

Saves #

What players see Where you change it
The save menu's look: six ready styles, every colour, fonts, sizes, rounding, spacing, your own images Tools > Shipready > Saves > Menu Style
The save menu's layout: tabs, newest first, the status line, how many cards show Menu Style > Layout
Every word of the save menu and its dialogs Menu Style > Words
Slot pictures, place names, play time and date formats The save settings and the Save Menu component
The saving indicator: where it sits, icon, text or both, how long "Saved" shows The Saving Indicator component, or the theme's messages
Save notices ("Autosaved", "Loaded an earlier copy") The Save Notes component, or the theme's messages
How many slots, autosaves and backups; when autosave runs Tools > Shipready > Saves > Setup Wizard

Tutorials #

What players see Where you change it
Coach marks or in-game hints, per tutorial or per step The Tutorial Flow and its steps
The look: dim, spotlight shape, outline, pointer, card colours and position, buttons, progress dots or counter The Tutorial Theme. Five presets ship
The message of a step, as full text, short text or icon The step, or the theme's Display As
Which device a step is for (keyboard and mouse, controller, touch) The step's Show On
Skip, Back and Next buttons The theme and the step; Player Options decides if players may skip
Sounds and animation The theme

Bug reports (testers) #

What testers see Where you change it
The form's look: colours, font, text size, your own panel, button and field images, width The Bug Report Theme. Four presets ship
Categories and severities, which parts a report includes, the privacy note Tools > Shipready > Playtest > Settings
Where the overlay, the stats, the error badge and the report button sit The Bug Report Theme
Every word The playtest text table
The keys that open the form and the overlay Tools > Shipready > Playtest > Settings

From code #

Every screen is also driven from code, and every list on this page has an API. Start with: PlayerOptions, GameLook, SettingsRuntime, SettingsPlayers, GameColors, MenuRoot, SaveKit, SaveMenu, TutorialFlow, BugReporter, GamePause, TextEntry, GameTrail.
