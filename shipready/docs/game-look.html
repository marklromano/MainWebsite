Game Look

One look for every screen players see. The menus and settings, the save menu, the bug report form and the tutorial cards take their colours, fonts and corner rounding from one asset, so the whole game changes with one edit.

Make it #

Launch Desk > Look > Create the game look. The asset is ShipreadyLook in Assets/RareGeometryData/Shipready/Resources. With no asset, every screen keeps the look of its own theme.

What you set #

Value Used for
Accent The selected control, the main button, highlights and pointers
Text on accent Words and icons on top of the accent colour
Panels Panels, dialogs and cards
Controls Buttons, rows, sliders and text fields
Shade behind screens Laid over the game behind an open screen; its alpha is how much of the game shows through
Text, Quiet text Titles and body text; hints, dates and other quiet text
Danger, Warning, Success Deleting and errors; things to look at; saved and done
Menu font, Heading font TextMesh Pro fonts for the menus and the save menu
Form and card font The font file for the bug report form and the tutorial cards
Text size Makes all text larger or smaller on top of each theme's sizes
Corner rounding How round panels are; cards and buttons follow in proportion

Start from has six schemes: Midnight, Daylight, Ember, Arcade, Parchment and High contrast. A scheme replaces the colours and the rounding; fonts, text size and the screens choice stay.

The preview shows a small pause menu in your colours. Under it the page tells you when a text colour is hard to read on its surface (a contrast below 4.5 to 1); the Readiness tab checks the same.

Which screens wear it #

Tick boxes for menus and settings, the save menu, the bug report form and tutorial cards. A screen left out keeps its own theme.

What the look does not change #

Each screen keeps its own theme for layout, sizes, images, sounds and animation. The look never writes into a theme asset: screens wear it on a copy made while the game runs. Remove the look asset and everything is as before.

While a player has High contrast on, the menus use their high-contrast theme instead of the look.

From code #

// A look per chapter, or a colour scheme the player picked.
GameLook.Use(winterLook);      // every open screen restyles at once
GameLook.Use(null);            // back to the asset in Resources

// A scheme made in code.
GameLook look = GameLook.Create(GameLookPreset.Ember);
look.Accent = teamColour;
GameLook.Use(look);

// Your own UI can read the same colours.
GameLook current = GameLook.Current;           // null when the game has no look
if (current != null) myPanel.color = current.Panel;
GameLook.Changed += Restyle;

To start a theme of your own from a look, call the theme's Wear once: SettingsMenuTheme.Wear(myTheme, look), MenuTheme.Wear(...), BugReportTheme.Wear(...), TutorialTheme.Wear(...).
