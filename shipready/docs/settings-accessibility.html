Docs/Shipready/Menus and settings

Accessibility

The default profile has an Accessibility tab. Every option works in the menu with no code; the ones your game needs to react to are available from code too.

Setting What the menu does What your game can do
Menu Size (75% to 150%) Scales the whole menu canvas. Read AccessibilityState.UiScale for your own HUD.
Text Size (80% to 160%) Scales every menu text. Read AccessibilityState.TextScale.
High Contrast Switches to the theme's high-contrast variant (text contrast at least 4.5:1, checked by a test). Read AccessibilityState.HighContrast.
Reduce Motion No screen fades, slides or focus zoom; instant color changes. Read AccessibilityState.ReducedMotion; multiply camera shake by AccessibilityState.CameraShakeScale (0 with reduced motion, otherwise the Camera Shake setting).
Focus Outline (thin / normal / thick) Thickness of the frame around the selected item. Nothing needed.
Sprint: Hold / Toggle (example) Stored only (Read). HoldOrToggleSettingDefinition.IsToggle(SettingsRuntime.Current, "accessibility.sprint-mode"), or listen to SettingsController.ValueApplied. Duplicate the asset for aim, crouch and so on.
Subtitles, Subtitle Size, Subtitle Background Applied by the Subtitles prefab. Call SubtitleDisplay.Show("Line.", seconds, "Speaker").
Subtitle Color, Speaker Name Color Applied by the Subtitles prefab (white and the prefab's own speaker color by default). Read AccessibilityState.SubtitleTextColor and AccessibilityState.SpeakerColor for your own subtitles.
Readable Font Every menu text and the subtitles switch to OpenDyslexic, a font made to be easier to read with dyslexia. Works with every theme and with translations (missing characters fall back to the theme's font). Read AccessibilityState.ReadableFont; each theme's Readable Font field holds the font (set your own, or leave it empty to turn the setting into a no-op).
Cursor Size (normal / large / extra large) Swaps the mouse pointer for a bigger white arrow. Nothing needed.
Color Blind Filter (off / protanopia / deuteranopia / tritanopia) and Filter Strength A full-screen color correction that moves colors a player can't tell apart into ones they can (Built-in pipeline, URP and HDRP). Off by default; the help picture shows colors that are often confused. Read ColorBlindFilter.Mode, ColorBlindFilter.Strength or ColorBlindFilter.CurrentMatrix (for example to recolor your own UI icons), or listen to ColorBlindFilter.Changed.

Optional settings (in Content/Settings/Optional/OptionalSettings, not in the default menu; add the ones your game supports, see Settings catalog):

Setting Tier What your game does
Sound Captions Auto Call SubtitleDisplay.ShowCaption("door creaks") for important sounds; it shows "[door creaks]" only while the setting is on.
Reduce Flashing Read Check AccessibilityState.ReduceFlashing and tone down strobes, muzzle flashes and screen flashes.
Head Bob Read Multiply your head bob by AccessibilityState.HeadBobScale (0 with Reduce Motion).
Aim, Crouch: Hold / Toggle Read Same as Sprint: HoldOrToggleSettingDefinition.IsToggle(...).

All values are also raised through AccessibilityState.Changed.

Subtitles #

  1. Drag Content/Prefabs/Subtitles.prefab into your first scene (or a scene that stays loaded).
  2. From your dialogue code: SubtitleDisplay.Show("Where is everyone?", 3f, "Mara"); Lines queue and play in order, in unscaled time (they keep going while paused).
  3. The player's Subtitles, Subtitle Size, Subtitle Background, Subtitle Color, Speaker Name Color and Readable Font settings apply automatically.
  4. Sound captions: SubtitleDisplay.ShowCaption("thunder rumbles"); (shown only when the player turned Sound Captions on).

Color blind filter #

The filter corrects the whole picture ("daltonization"): it works out which color differences a player with that kind of color blindness loses, and moves them into colors they can see. Strength blends from no change (0%) to the full correction (100%).

  • Built-in pipeline: a command buffer after the image effects of every game camera, added only while the filter is on. Nothing is added to your scenes.
  • URP: a Channel Mixer on Shipready's own global Volume (priority 1000). Your volumes and URP assets are not changed.
  • HDRP: the same, through Shipready's HDRP integration (it compiles only when HDRP is installed).

Design tip: the filter helps, but don't rely on color alone. Pair colors with shapes, icons or text in your HUD.

Keyboard, controller and mouse #

Every screen is fully usable with a keyboard or a controller; focus is always visible and is restored when you go back. Rebinding protects the menu controls, so a player can't lock themselves out.

Menu narration (a hook for text-to-speech) #

The optional Menu Narration setting (accessibility.narration) turns on MenuNarration: the menu sends each screen's title and what the player focuses (a button's label; a setting's name, value and help) to MenuNarration.Spoken. Connect your platform's text-to-speech there:

MenuNarration.Spoken += text => MyTextToSpeech.Speak(text);

Add the Narration Log component to see the texts in the Console while you set it up.

Not supported: screen readers #

The menus are not read aloud by system screen readers (Narrator, NVDA, VoiceOver, TalkBack) on their own; use the narration hook above with a text-to-speech of your choice. Unity's uGUI has no built-in screen reader support, and Shipready does not add one. If your game needs a screen reader, plan for a dedicated solution.
