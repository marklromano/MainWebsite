Quick Start

Shipready needs Unity 6000.0.85f1 or newer, the Unity UI package (it is in every new project) and TextMesh Pro's essential resources (Unity offers to import them the first time; say yes). It works in the Built-in, URP and HDRP render pipelines, with either input system.

1. Connect your game #

  1. Open Tools > Shipready > Launch Desk.
  2. On the Start tab, choose how Shipready joins your project: - New game: the open scene becomes your menu scene. The game starts on the title screen. - Existing game: the open scene is a level. The menus go in beside what is there and stay hidden until the pause key opens them. Your Event System, canvases, cameras and scripts are left alone. - Keep my own menus: only settings and saves are set up. You call them from your own screens.
  3. Read the plan. Every line is something Shipready will add, and nothing else changes.
  4. Press Connect. Scene changes are one undo step (Edit > Undo).

Your own copies (the settings profile, the mixer, Player Options, the save settings) are made in Assets/RareGeometryData/Shipready. Updates of Shipready never touch that folder.

2. Press Play #

  • The title screen and main menu work with mouse, keyboard and controller.
  • Settings change the real game: resolution with a "keep these settings?" countdown, quality, volumes, key rebinding, accessibility.
  • Escape (or Start on a controller) pauses.
  • F5 saves and F9 loads while you test in the Editor. The save menu shows slots with pictures, dates and play time.

3. Choose what players get #

On the Player Options tab, pick a starting point (Locked down, Standard, Full control), then set a whole category or one setting at a time: players change it, see it locked, or do not see it. See Player Options.

4. Give it your look #

On the Look tab, press Create the game look, pick a starting scheme and change any colour. The menus, the save menu, the bug report form and the tutorial cards all follow. See Game Look.

5. Check before you ship #

On the Readiness tab, press Inspect. Fix blockers first, then warnings, then run the checks that are marked not tested. Export report saves the result as a page you can share. See Ship Readiness Checker.

If something does not work #

Open the question mark in the Launch Desk, press Copy system info, and send it with what you saw to the support address shown there. The Readiness tab also explains most setup problems and fixes many with one button.
