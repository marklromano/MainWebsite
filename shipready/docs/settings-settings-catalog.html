Docs/Shipready/Menus and settings

Settings catalog

A Settings Profile lists the tabs (categories) and settings your menu shows. Shipready ships a profile with the full launch catalog; add, remove, reorder or create settings in the menu builder's Settings tab.

Tiers: how a setting reaches your game #

Tier Meaning Examples
Auto Shipready applies it for you. Nothing to do. Resolution, VSync, quality, volumes, post effects, menu size, language
Connect It drives something in your scene: a component (for example Camera Field Of View Target), a Setting Event Binder with UnityEvents, or your callback. Field of view, your own custom settings
Read Shipready stores it; your code reads it when it needs it. Difficulty, camera shake, vibration, hold or toggle

The badge next to each setting in the window shows its tier.

Tabs in the default profile #

Display, Graphics, Audio, Controls, Accessibility, Gameplay. Settings that need something the project doesn't have (a render pipeline, the Input System, a mixer, a second monitor) are hidden automatically, with the reason shown in the catalog. See the Settings reference for every setting.

Add a setting from the catalog #

Settings tab > Catalog: search, then Add. Shipready copies the setting next to your profile (your copy, safe from updates). Remove takes it out again. Shipready's own profile can't be edited: make an editable copy first (Home tab, step 1).

Optional settings #

Content/Settings/Optional/OptionalSettings holds settings many games want but not every game can use, so they are not in the default menu. Add the ones your game supports in the menu builder: Settings tab > Add optional settings (check boxes, then Add checked). You can also find them in the Catalog, or add the whole profile to your profile's Includes.

Setting Id Tier
Settings Preset gameplay.settings-preset Read (picking one sets every value it lists: Comfort, Clean Image)
Sound Captions accessibility.sound-captions Auto (with SubtitleDisplay.ShowCaption)
Reduce Flashing accessibility.reduce-flashing Read
Menu Narration accessibility.narration Auto (your text-to-speech listens to MenuNarration.Spoken)
Head Bob gameplay.head-bob Read (AccessibilityState.HeadBobScale)
View Distance gameplay.view-distance Connect (Camera View Distance Target)
Look Smoothing, Mouse Acceleration controls.look-smoothing, controls.mouse-acceleration Read
Left / Right Stick Dead Zone controls.left-dead-zone, controls.right-dead-zone Read
Swap Sticks controls.swap-sticks Read
Aim Assist, Aim Assist Strength controls.aim-assist, controls.aim-assist-strength Read
Aim, Crouch (hold / toggle) accessibility.aim-mode, accessibility.crouch-mode Read
Night Mode audio.night-mode Read
Grass And Detail, Ambient Occlusion, Reflections graphics.density, graphics.ambient-occlusion, graphics.reflections Read
Show HUD, HUD Size, HUD Opacity gameplay.show-hud, gameplay.hud-scale, gameplay.hud-opacity Read
Crosshair, Crosshair Color gameplay.crosshair, gameplay.crosshair-color Read
Units gameplay.units Read
Autosave, Tutorial Hints gameplay.autosave, gameplay.tutorial-hints Read
Camera Distance gameplay.camera-distance Read

How your game uses each one #

In the menu builder: Settings tab > Add optional settings: check the ones your game supports, then Add checked.

Without code: select a GameObject, Settings tab > Custom setting > Add event binder to selection, type the setting's id, and wire its UnityEvent (float, int, bool or string) to your script. It fires at startup and whenever the player applies settings.

In C# (read when you need the value, or listen once):

using RareGeometry.Shipready.Settings;

var settings = SettingsRuntime.Current;

// Settings Preset: nothing to do. Picking Comfort or Clean Image sets the values the preset lists;
// make your own with Create > Rare Geometry > Settings Menu > Settings Preset and add it to the choice.

// Sound Captions: the Subtitles prefab shows them only when the player turned them on.
SubtitleDisplay.ShowCaption("door creaks");

// Menu Narration: speak what the menu sends while it's on.
MenuNarration.Spoken += text => MyTextToSpeech.Speak(text);

// Reduce Flashing
float flashStrength = AccessibilityState.ReduceFlashing ? 0.2f : 1f;

// Head Bob (0 with Reduce Motion)
bobOffset *= AccessibilityState.HeadBobScale;

// View Distance (Connect): add Camera View Distance Target to the camera, or the Check tab adds it.

// Look Smoothing, Mouse Acceleration
float smoothing = settings.GetFloat("controls.look-smoothing");
lookDelta = Vector2.Lerp(lookDelta, rawLook, 1f - smoothing * 0.9f);
bool accelerate = settings.GetBool("controls.mouse-acceleration");

// Dead zones (Input System: set the stick processors at startup and on change)
float leftDeadZone = settings.GetFloat("controls.left-dead-zone", 0.15f);
float rightDeadZone = settings.GetFloat("controls.right-dead-zone", 0.15f);
moveAction.ApplyParameterOverride("stickDeadzone:min", leftDeadZone);

// Swap Sticks
bool swap = settings.GetBool("controls.swap-sticks");
Vector2 move = swap ? lookInput : moveInput;

// Aim Assist, Aim Assist Strength
float assist = settings.GetBool("controls.aim-assist", true) ? settings.GetFloat("controls.aim-assist-strength", 1f) : 0f;

// Aim, Crouch: hold or toggle
bool toggleAim = HoldOrToggleSettingDefinition.IsToggle(settings, "accessibility.aim-mode");
bool toggleCrouch = HoldOrToggleSettingDefinition.IsToggle(settings, "accessibility.crouch-mode");

// Night Mode: switch to a compressed mixer snapshot
(settings.GetBool("audio.night-mode") ? nightSnapshot : normalSnapshot).TransitionTo(0.5f);

// Grass And Detail, Ambient Occlusion, Reflections
Terrain.activeTerrain.detailObjectDensity = settings.GetValue("graphics.density") == "low" ? 0.25f : settings.GetValue("graphics.density") == "medium" ? 0.6f : 1f;
ssaoFeature.SetActive(settings.GetBool("graphics.ambient-occlusion", true));
reflectionProbe.enabled = settings.GetBool("graphics.reflections", true);

// Show HUD, HUD Size, HUD Opacity
hudCanvas.enabled = settings.GetBool("gameplay.show-hud", true);
hudRoot.localScale = Vector3.one * settings.GetFloat("gameplay.hud-scale", 1f);
hudGroup.alpha = settings.GetFloat("gameplay.hud-opacity", 1f);

// Crosshair, Crosshair Color ("off", "dot", "cross", "circle"; colors as in TextColors)
crosshair.sprite = crosshairSprites[settings.GetValue("gameplay.crosshair")];
crosshair.color = TextColors.Get(settings.GetValue("gameplay.crosshair-color")) ?? Color.white;

// Units ("metric" or "imperial")
string speed = settings.GetValue("gameplay.units") == "imperial" ? $"{kmh * 0.621f:0} mph" : $"{kmh:0} km/h";

// Autosave, Tutorial Hints
if (settings.GetBool("gameplay.autosave", true)) SaveGame();
if (settings.GetBool("gameplay.tutorial-hints", true)) ShowHint("Press E to open doors");

// Camera Distance (third person)
followCamera.distance = baseDistance * settings.GetFloat("gameplay.camera-distance", 1f);

// React to changes instead of polling:
settings.ValueApplied += definition => { if (definition.Id == "gameplay.show-hud") hudCanvas.enabled = settings.GetBool("gameplay.show-hud", true); };

Reading one: SettingsRuntime.Current.GetBool("gameplay.show-hud"), GetFloat("gameplay.hud-scale", 1f), GetValue("gameplay.crosshair"), or listen to SettingsController.ValueApplied.

Per-setting options #

Every setting asset has these fields (Inspector), all optional:

Field What it does
Hide In Menu Keeps the setting working but doesn't show it.
Show When Id / Show When Values Shows it only while another setting has one of these values (comma-separated). Shipready uses it for Vibration Strength (Vibration on), the subtitle options (Subtitles on), Aim Assist Strength and Crosshair Color.
Platforms Desktop, Mobile, Console, Web. Elsewhere the setting is hidden and not applied (Cursor Size and Mute In Background: desktop and web; Monitor: desktop).
Requires Restart After Apply, a short notice says the change takes effect after a restart.
Help Image A picture shown with the help line while the setting is focused.

Presets: many settings at once #

A Settings Preset (Create > Rare Geometry > Settings Menu > Settings Preset) lists setting ids and values. Put presets in a Settings Preset Choice setting (the optional gameplay.settings-preset has Comfort and Clean Image) and players pick one in the menu; or call SettingsRuntime.Current.ApplyPreset(preset) and then Apply(). Ids your profile doesn't have are skipped.

Create your own setting #

Settings tab > Custom setting (with UnityEvents): choose Toggle, Slider, Whole number or Choice, give it an id (for example gameplay.hints), a label and a tab, and click Create and add to profile. Then select a GameObject and click Add event binder to selection: its UnityEvents fire with the new value whenever the player applies settings.

Needs connection #

The Check tab lists Connect settings that nothing in the open scene listens to yet (for example Field of View without a camera target), each with a one-click fix.
