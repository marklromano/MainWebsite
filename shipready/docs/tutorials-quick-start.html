Docs/Shipready/Tutorials

Quick Start

See it working (1 minute) #

  1. Choose Tools > Shipready > Tutorials > Open Demo > Menu Tour (uGUI).
  2. Press Play. The screen dims, the Play button is spotlighted and a tip card explains it.
  3. Click Play in the game: the step finishes and the tour moves on.
  4. On the last step but one, click Make it yours to switch between the five built-in looks.

Your own tutorial (5 minutes) #

  1. Open your scene.
  2. Select the buttons or objects the tutorial should point at, in the order the player meets them.
  3. Choose Tools > Shipready > Tutorials > Add Selected As Steps. You get a Tutorial Flow with one step per object. Steps that point at a button already wait for a click on it.
  4. Select a step and write its heading and text in the Inspector. With Live Preview on (the default), the Game view shows the step without pressing Play.
  5. Press Play.

What next #

  • Change how each step finishes: add a rule such as Key Rule or Area Rule to the step (Finishing a Step).
  • For an action game, set the flow's Style to Hint: small tips that never block or pause play (Coach Marks and Hints).
  • Pick a look under Theme Preset, or make your own theme (Make It Yours).
  • If something doesn't happen, open Tools > Shipready > Tutorials > Why Is This Step Waiting.
