Troubleshooting

Start with Tools > Shipready > Playtest > Why Isn't It Working. It checks everything the form needs and offers a one-click fix where there is one.

What you see Why, and what to do
F8 does nothing in the Editor Click the Game view first so it has the keyboard. Check Settings > Include In isn't Never. In Why Isn't It Working, click Open the Form Now while playing: if that works, your game is taking the key (see Adding it to your own game)
F8 or the key above Tab does nothing while typing On purpose: Shipready ignores its keys while one of your text fields has focus
My game moves or shoots while I type in the form Your game's input keeps running. Switch it off on BugReporter.FormOpened (Adding it to your own game)
The game unpauses after the form, or stays paused Your game paused itself (time scale 0) while the form was open, and Shipready put back the time scale from before. If your game pauses itself, switch off Pause While Open and pause from BugReporter.FormOpened
"Go to where the tester was" lands in the wrong place Shipready used a different camera than the player's. Set BugReporter.TesterCamera
A report has no log Your game set Debug.unityLogger.logEnabled = false. Why Isn't It Working warns about it while playing
An attachment is missing It was over Max Attachment Megabytes, or its callback threw; the report's recent events say which
A long log line ends in "characters cut" Lines and stack traces are kept up to 16,000 characters each
My script can't see BugReporter Your assembly definition needs a reference to RareGeometry.Shipready.Playtest
F8 does nothing in a build The build isn't a Development Build and Include In is Development Builds Only. Tick Development Build, or set Always
"No way to read the key" Active Input Handling is the Input System but the package isn't installed. Install it, or set Both in Player settings
The form has no screenshot markup The uGUI package isn't installed, so the simple form is used. Install uGUI for the full form
A report has no screenshot The game has no graphics device (a headless build) or the tester unticked it
The replay is missing Settings > Replay Seconds is 0, the platform can't read the GPU back, or the tester unticked it
"Slack: not sent" The webhook address is wrong (it starts with https://hooks.slack.com/), or the device is offline. The zip is safe on the device
"Discord: not sent" The webhook address is wrong, or the device is offline. The zip is safe on the device, and Shipready tries again next start
"http is blocked by Player Settings" Use an https address, or allow http in Player settings (Allow downloads over HTTP)
A stack line in the Inbox isn't blue The script isn't in this project at that path, for example a build from another branch
Go to where the tester was can't find the scene The scene was renamed or isn't in this project
The error badge never shows Settings > Error Badge is off, or the theme's Badge Display is None
My own font looks blurry Use a font with a large enough source size, or raise Text Scale

Known limits: the replay is a few pictures a second, not video. Android and WebGL are checked to compile; they have not yet been run on a phone or in a browser.
