All In One Prefab Builder Kit · v0.8.0

Prefab Builder documentation

Quick start: five minutes

  1. Import the package from the Asset Store. Everything lands in Assets/AllInOnePrefabBuilderKit/.
  2. Open Tools > All In One Prefab Builder > Prefab Builder (Alt+Shift+W) and click Try the sample kits, or add your own pack with Tools > All In One Prefab Builder > Add Pack...
  3. On the review screen, check the categories, fronts and grid cell. Pieces marked ! or ? deserve a look. Click Create Kit.
  4. Pick a piece in the palette and click in the Scene view. R turns it, T tilts it, green means it fits.

Version 0.8.0. These pages describe what is in this version; later versions add facades (Dress), the Rooms mode, the map builder and scene splitting.
