Upgrading

How to update the Prefab Builder, and what changes for you in each version. The full list of changes is in CHANGELOG.md, in the product folder.

How to update #

  1. Save your scene.
  2. Delete the old product folder: Assets/AllInOnePrefabBuilderKit (before 0.8 it was called Assets/AllInOneWorldBuilderKit). A package update only adds and replaces files; it never deletes them, so files an older version had and a newer one doesn't would stay behind, and old scripts among them can stop the project compiling.
  3. Import the new package from the Package Manager (My Assets).

Your own work isn't in the product folder, so deleting it loses nothing: your kits, rule sets, palettes and placeable copies are in your data folder (Assets/AllInOnePrefabBuilderData, or the folder you chose), the project's settings in ProjectSettings/AllInOneWorldBuilderSettings.asset, and your hotkeys and tool presets in Unity's own preferences. Pieces you placed are ordinary objects in your scenes.

1.0.0 #

A free update for everyone who owns 0.8. Nothing to do: kits, rule sets, palettes, hotkeys and scenes made with 0.8 all carry over, and every menu item, hotkey and public C# type and member of 0.8 is still there (a test checks this).

  • Unity 6000.0 LTS or newer (0.8 needed 6000.3).
  • Home (⌂) opens the first time for someone with no kits yet. You can open it any time from the ⌂ button.
  • Some tools and options have clearer names: Fix > Similar and Physics > Drop (they shared names with other tools), Allow overlaps (was Place over red), Same floor type only (Stay on this floor), Ground pieces sit on top (Floors on top of the ground), Whole panels only (Fixed), Panels face in (Fronts in), Around the selection (Inverse), Facing (Turn them). They do what they did; your settings for them are kept.
  • Settings show in plain words with units; the rarely changed ones are under Advanced.
  • Tool picks are kept per project now. Picks you made in 0.8 (brush pieces, slots, recent decals) start empty once in each project; pick them again.
  • Sign text finds the board more reliably. Signs placed with 0.8 keep their text where it is until you change them.

0.8.0 #

  • The product folder was renamed to AllInOnePrefabBuilderKit, and the data folder to AllInOnePrefabBuilderData (an old data folder is renamed for you the first time the kit loads, so your kits keep working).
  • Needed Unity 6000.3 or newer.
