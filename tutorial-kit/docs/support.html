Support

Where to get help #

  • Documentation: https://romanoassets.github.io/tutorial-kit/docs/
  • Discord: https://discord.gg/AmpBDxRAKu
  • Ask in #help, report problems in #bug-reports, suggest ideas in #feature-requests, with the Tutorial Kit tag.
  • Report a bug: https://github.com/romanoassets/RomanoAssetSupport/issues
  • Search the open issues first, then use the Bug report form and pick this kit.
  • Website: https://romanoassets.github.io/tutorial-kit/
  • Email: marklromano@outlook.com

What to include #

Open Tools > All In One Tutorial Kit > Help and Support and press Copy system info: it copies the kit version, Unity version, render pipeline, platform and input handling. Paste it into your post, then add what you did, what you expected, what happened, and any Console errors.
