Changelog

All notable changes to the All In One Tutorial Kit are listed here, newest first, in the Keep a Changelog style.

[1.0.0] - 2026-11-08 #

Added #

  • First release. Tip card placement that keeps the card on screen and off its target, Help and Support window.
  • Tutorial Flow with steps as child objects, Next, Back, Skip, Restart, run once per player and resume, on real time so it works while the game is paused. Progress in PlayerPrefs or your own store.
  • Targets: uGUI elements, UI Toolkit elements, 2D and 3D world objects (renderers, colliders or position, any camera), screen areas, or none. Off-screen world targets get an edge marker.
  • Completion rules: Click Target, Timer and Event, combined as any or all.
  • uGUI presenter: dim overlay with a crisp spotlight hole (rounded rectangle, circle or oval), outline ring, pointer and a tip card placed beside the target, with an input gate (only the target, only the card, or nothing blocked).
  • Five built-in looks: Clean Dark, Minimal, Mobile Casual, Sci-Fi HUD, Fantasy Parchment.
  • Bring your own UI through ITutorialPresenter; every word through TutorialText.Translate.
  • "Why Is This Step Waiting" window and in-game debug overlay; Star Garden menu tour demo.
  • Changing the look, the words or a step's settings in the Inspector during Play redraws the card that is showing.
  • Targets Found By Id (Tutorial Target Id component, or TutorialTargets.Register) for spawned prefabs, pooled UI and objects in other scenes; When Target Missing (wait, show the card, or skip); uGUI targets in a Scroll Rect are scrolled into view.
  • Clicks only count when the button really takes them; gamepad and keyboard Submit on the highlighted button; gamepad players get it selected; keys typed into text fields are ignored.
  • Suspend and Resume (and SuspendAll) for pause menus and loading screens; one coach-mark flow at a time (others wait).
  • TutorialFlow.Find, PlayById, RefreshAllViews and AnyEvent (one event stream for analytics, the kit sends nothing).
  • Progress per save slot (TutorialProgress.UseProfile), ClearAll and ClearProgress; resume finds the saved step even after steps are inserted, moved or removed.
  • Sort Order on the flow; Skip Key is None by default; Add Step templates; the step Inspector says when the step finishes, lists its problems and has Test From This Step.
  • Demos: Star Garden menu tour (uGUI), First Person Basics (3D in-game hints), Platformer Hints (2D) and Strategy Tour (UI Toolkit), each one click away under Tools > All In One Tutorial Kit > Open Demo.
  • In-game hint style: a small tip that never dims, blocks or pauses play, at the bottom, top, centre or beside its target.
  • More ways to finish a step: keys, Input System actions, gestures (tap, long press, swipe, drag, pinch), reaching an area, moving a distance, looking at something, a counter, and a condition on any field or property.
  • Make it yours: Display As (full, short, icon, icon and short text, none), card position (beside the target, any side, screen top or bottom, custom point), counter or progress dots, fade/scale/slide entrance, your own card, button and pointer pictures (9-sliced, tinted), step, click and finish sounds, and a different look for any single step.
  • UI Toolkit presenter: the same spotlight, pointer and tip card drawn with UI Toolkit, used automatically when uGUI isn't in the project (or add it to a flow to use it anyway).
  • Flow control: skip a step the player already knows, branch or loop to any step, show a hint until it is learned, Escape to skip. Tutorial Trigger starts a flow when the player enters an area, the first time something is seen, when an object turns on, or after a delay. Presets: Menu Tour, Movement Basics, First Time Hint.
  • Interaction Kit Rule (finish a step by using an All In One Interaction Kit object, no link between the kits needed) and Visual Scripting Event Rule (a graph's Custom Event finishes the step).
  • Button pictures: give a step a Glyph Action (Jump, Interact, Move...) and its card shows the right picture for the keyboard, Xbox, PlayStation, Switch or touch screen, switching live. Ships Kenney's Input Prompts (CC0).
  • Scene Overview: every tutorial in the scene, the problems found and a one-click fix for each.
  • Live preview: select a step and the Game view shows it without pressing Play (Tools > All In One Tutorial Kit > Live Preview).
  • Editor: Tutorial Flow inspector with the step list, Create Tutorial Flow, Add Selected As Steps, Open Demo, Scene view gizmos.
