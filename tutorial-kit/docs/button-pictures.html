Docs/Tutorial Kit/Features

Button Pictures

Set a step's Glyph Action (for example Jump) and its card shows the right picture for the player's device: Space on a keyboard, A on Xbox, Cross on PlayStation, B on Nintendo Switch, a swipe on a touch screen. It switches live when the player picks up another device, with either input system.

The kit's set (Default Input Glyphs, made from Kenney's Input Prompts, CC0) has these actions: Confirm, Back, Jump, Interact, Attack, Aim, Move, Look, Menu, Tap, Hold, Swipe, Pinch.

Your own set #

Choose Assets > Create > All In One Tutorial Kit > Input Glyph Set, add your actions and pictures, and set it on the flow's Glyphs field. A device with no picture falls back to the keyboard picture.

On light cards, the theme's Icon Plate Color puts a plate behind white button pictures so they stay readable.

Words that fit every device #

The picture changes with the player's device; the words don't. Write the action, not the key ("Jump onto the ledge", not "Press Space to jump onto the ledge"), and let the button picture show which button to press. For per-device words, translate them through TutorialText.Translate and call TutorialFlow.RefreshAllViews() when the device changes.
