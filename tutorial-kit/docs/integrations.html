Docs/Tutorial Kit/Features

Integrations

The kit needs no package. These work automatically when their package or kit is in your project.

With What you get
uGUI (in every Unity template) The kit's tip card, spotlight and input gate for uGUI.
UI Toolkit (built into Unity) UI Toolkit targets, and a UI Toolkit tip card. It is used when uGUI isn't in the project; add UI Toolkit Tutorial Presenter to a flow to use it anyway.
Input System package Keys, pointer, touch, gamepad detection and the Input Action Rule. With Input Handling set to Both, the Input System is used.
Visual Scripting package Visual Scripting Event Rule: a graph's Custom Event finishes a step. Any graph can also call Mark Done on a rule or Next on a flow.
All In One Interaction Kit Interaction Kit Rule: using a door, switch or pickup finishes a step. Neither kit needs the other.

Saving progress with your save system #

Progress goes to PlayerPrefs by default. To keep it in your own saves, implement ITutorialProgressStore (five small methods: get and set the step, get and set done, clear) and set it once at start:

TutorialProgress.Store = new MySaveSystemProgressStore();
