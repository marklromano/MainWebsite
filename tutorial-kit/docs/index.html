Docs/Tutorial Kit/Start here

All In One Tutorial Kit documentation

In-game tutorials and onboarding without code: spotlight any button or object, show a tip, and finish each step when the player really does it. uGUI, UI Toolkit, 2D and 3D.

  • Unity 6000.0+
  • Built-in, URP & HDRP
  • No code needed
  • Full C# source
  • Version 1.0.0
Get started

Quick start: five minutes

  1. Import the package. Everything lands in Assets/AllInOneTutorialKit/.
  2. Open Tools > All In One Tutorial Kit > Open Demo > Menu Tour (uGUI) and press Play to see it work.
  3. In your own scene, select the buttons or objects to point at and choose Add Selected As Steps.
  4. Write each step's words and press Play. Live Preview shows a step without pressing Play.
