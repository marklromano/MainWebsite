Flows and Steps

A Tutorial Flow is one tutorial. Its steps are its child objects with a Tutorial Step component, shown in order from top to bottom. Reorder steps by reordering the children, or with the arrows in the flow's Inspector.

The flow #

Setting What it does
Theme Preset / Theme The look (see Make It Yours).
Style Coach Mark dims and waits; Hint is small and never blocks. Steps can override it.
Input Gate What the player can click: only the target, only the card, or everything. Steps can override it.
Start On Scene Start, or Manually (a trigger, a button, a UnityEvent or code calls Play).
Run Once Per Player Once the player finishes or skips it, it never runs again for them (on this install, or in this save slot with a profile: see Progress).
Resume Where Left If the player quits halfway, the flow continues from the same step next time.
Show Until Learned For repeating hints: stop after the player finished it this many times (0 for no limit).
Flow Id The name progress is saved under. Keep it once players have it.
Glyphs The button picture set (see Button Pictures).
Presenter Your own UI (see Extending). Empty uses the kit's tip card.
Next Keys / Skip Key Extra keys for Next, and a key for Skip (none by default: many games open their pause menu with Escape; the Skip button always works).
Wait For Other Tutorials When another coach-mark flow is showing, wait until it ends before starting. On by default.
Sort Order Draw order of the dim and card above your UI. Raise it if one of your canvases uses a higher Sort Order (the highest is 32767).

Events: On Started, On Step Shown (with the step's number), On Completed, On Skipped.

The step #

Setting What it does
Title, Text The tip card's words. Short sentences work best.
Short Text A few words for compact cards and hints.
Icon A picture shown when the look's Display As uses icons.
Glyph Action Shows the button picture for this action on the player's device (Jump, Interact...).
Target What the step points at (see Targets).
When Target Missing Wait for it (default: nothing shows or blocks until it appears), show the card anyway, or skip the step.
Finish When Any rule or all rules. A step with no rule finishes with Next.
Next Button Auto shows it when the step has no rule.
Optional Next can pass over the step even when its rules aren't done.
Skip If Already Done If the player already did it (its rules are done the moment it starts), skip it.
Next Step Where to go next: empty for the following step, or any step to branch or loop.
Theme Override, Display As, Position A different look, message or card position for this step only.

Events: On Shown and On Completed (not called when the step is skipped).

Starting a flow #

  • On Scene Start: it plays as soon as the scene starts.
  • Tutorial Trigger component: when the player enters an area (3D or 2D trigger), the first time an object is seen on screen, when an object turns on, or after a delay.
  • Play from a UnityEvent (a button's On Click) or from code: flow.Play().

Progress #

Progress is saved in PlayerPrefs under RomanoAssets.TutorialKit.<flow id>. PlayerPrefs belong to this install of the game: for save slots or several players call TutorialProgress.UseProfile("slot-2"), or keep progress with your game's saves by setting TutorialProgress.Store to your own ITutorialProgressStore (see Extending). TutorialProgress.ClearAll() forgets everything (a new game, or "Reset tutorials" in your options). Restart starts one flow again from its first step.

Each step saves a stable key next to its position, so inserting, moving or removing steps in an update never resumes a player at the wrong step.

While testing, the step's Inspector has Test From This Step in Play mode: it starts the flow at that step even if you finished it before.

Pausing #

Tutorials run on real time, so they keep working while your game is paused (Time.timeScale = 0): good for menu tours. When your pause menu, a dialogue or a loading screen opens over a running tutorial, call flow.Suspend() (or TutorialFlow.SuspendAll(true)) and Resume() when it closes: nothing shows or blocks meanwhile, and its rules and timers wait.
