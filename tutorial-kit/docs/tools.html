Docs/Tutorial Kit/Features

Tools

Everything is under Tools > All In One Tutorial Kit.

Tool What it does
Create Tutorial Flow A new flow with one step.
Create From Preset Menu Tour (coach marks), Movement Basics (in-game hints), First Time Hint (shown the first time something is seen).
Add Selected As Steps Select buttons or objects, get one step per object with its target set; steps on buttons wait for a click. Picking a button's label or icon points at the button itself.
Add Step Ready-made steps: Explain Something (Next button), Click A Button (select it first), Press A Key (in-game hint), Walk Somewhere (in-game hint), Wait For A Game Event. Added to the selected flow.
Live Preview Select a step and the Game view shows it without pressing Play. Nothing is added to your scene. Tick to turn off.
Why Is This Step Waiting Every flow in the open scenes, and while playing, what each step waits for and what is wrong with its target. Buttons to step forward, skip or restart.
Scene Overview Every tutorial in the open scenes, and the problems found with a one-click fix for each (every fix is one undo).
Open Demo The four demos.
Help and Support Version, documentation, Discord, bug tracker and email, and Copy system info for bug reports.

In the Inspector #

The Tutorial Flow Inspector lists the steps in order with Edit and move buttons, Add Step, and Restart, Next and Skip while playing.

At the top of the Tutorial Step Inspector, a box says in plain words when the step finishes ("a click on Play Button, or the Next button") and what it points at, lists anything wrong with it (with a fix button), and while playing has Test From This Step and what the step is waiting for right now.

In the Scene view #

Select a flow or a step to see a box and the step number on each world target.

In your game #

Add a Tutorial Debug Overlay to any object and press F8 in a test build to see what each running flow waits for, with a box around each target.
