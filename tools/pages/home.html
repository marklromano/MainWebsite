How every kit is built

Tools you can trust in a real project

  • Full C# source

    Read it, step through it, change it. Nothing is hidden in a DLL.

  • No package dependencies

    Built on Unity's own modules only. Import it and it works; nothing else is installed.

  • Your files stay yours

    Your art packs are never modified, and your own data lives in its own folder, safe across updates.

  • Help inside the editor

    Tooltips on every control, a first-run tour, and offline documentation that ships with the kit.

  • Undo that works

    Every action is one Undo step. Try things freely.

  • Built-in, URP and HDRP

    Tested on all three render pipelines, from Unity 6000.0 LTS to the newest Unity 6, with Domain Reload on or off.

About

Made by a developer, for developers

Romano Assets is Mark Romano, a solo developer making games in Unity. Whenever a job in the editor gets slow or repetitive, I build a tool for it. The tools that prove themselves on my own game, Pawnheads (a co-op physics game about running a tiny pawn shop), get polished, documented and published here.

That means every kit has already been used in a real project before you see it, and the person who wrote it reads every bug report.
