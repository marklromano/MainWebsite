How it works

Your first tutorial in three steps

  1. Add your buttons as steps

    Select the buttons or objects your tutorial should point at and choose Tools > All In One Tutorial Kit > Add Selected As Steps.

  2. Write the words

    Each step's Inspector says in plain words when it finishes. Live Preview shows the step in the Game view without pressing Play.

  3. Press Play

    The kit spotlights each target, places the tip card beside it and moves on when the player does it.

Features

Fits almost any game, and every part is yours to change

Two styles

Coach marks and hints
  • Coach marks: the screen dims around a crisp spotlight (rounded, circle or oval), a pointer shows the way, and only the target can be clicked.
  • In-game hints: a small tip with the right button picture that never dims, blocks or pauses play.
  • Off-screen objects get an arrow at the screen edge that points the way.

Any target

  • uGUI and UI Toolkit elements
  • 3D models, sprites, 2D and 3D colliders
  • Spawned and pooled objects, found by id
  • Lists scroll to the item

14 ways to finish a step

  • Click, a key, an Input System action, a gesture
  • Walk, look, reach an area, wait
  • Collect a number of things, a condition, a UnityEvent
  • Visual Scripting and Interaction Kit events

Every input

  • Mouse, keyboard, gamepad and touch
  • Input Manager, Input System or both
  • Button pictures for keyboard, Xbox, PlayStation, Switch and touch, switching live

Make it yours

  • Five looks to start from, switch them live
  • Every part can be changed or turned off
  • Your own pictures, font and sounds, or your own UI

Built for your own game

  • Waits for a missing target without blocking anything
  • Suspend and Resume for pause menus
  • Progress per player and save slot

Tools that explain themselves

Editor
  • Why Is This Step Waiting: what a step waits for, in plain words, in the editor and as an in-game overlay.
  • Scene Overview: finds problems in your tutorials and fixes most of them in one click.
  • Live Preview, presets, ready-made steps and Test From This Step.

Good to know

Limits, stated up front

  • Tutorials for players, not Unity Editor tutorials for developers.
  • No analytics service: the kit raises events you can send anywhere, and sends nothing itself.
  • VR and XR input are not supported in this version; no voice-over.
  • Not yet tested on devices: iOS, Android phones, consoles, Mac and Linux players.
