Docs/Responsive FX/Hit feedback

Setup Wizard

Tools > Responsive FX > Setup Wizard adds Hit Feedback to your own enemies, players and props, one or a whole folder at once. It also opens from the right-click menu in the Hierarchy and the Project window (Responsive FX > Add Hit Feedback (Setup Wizard)).

1. What to set up #

Select objects and press Use Selection. You can pick:

  • prefabs in the Project window,
  • a folder: every prefab in it,
  • objects in the scene.

For each one the wizard shows what it found: the renderers it will flash (meshes, skinned meshes, sprites), what will be pushed (Rigidbody, Rigidbody 2D, Character Controller, NavMesh Agent or the transform), whether an Animator will pause in hitstop, and whether it already has health. Problems are listed under it, for example "Marked Static" (static batched objects can't flash) or "Has missing scripts" (reimport it first).

2. The feel #

Pick a Preset, or drag in a profile you already made. You can change everything later. Adding to a game that already has combat? Pick Existing Game (safe): numbers, flash, bar, sound and sparks, and nothing that moves, freezes or scales your objects or touches your camera.

3. Who controls health? #

  • Find it for me (recommended): looks for your own health script by name (Health, HP, Damageable, Stats...). When it finds one it adds a Hit Feedback Bridge that watches its health value, so your game stays in charge. When there is none it adds Responsive FX's Health. It never adds a second health system next to yours.
  • My game already has health: always adds a Bridge (watching your health script when one is found; otherwise connect your events to it, see Hook it into your game).
  • Add Responsive FX's basic Health with a Max health: Responsive FX's Health component, which plays feedback by itself on every change. Skipped when the object already has health.
  • Feedback only: just Hit Feedback. You call HitFeedback.Hit(target, amount).

Ragdolls (three or more jointed bones) get knockback and squash switched off for that object, because physics owns the body. The list shows "your health: EnemyStats.currentHealth" or "ragdoll" when it spots them.

Extras #

  • This is the player: adds Player Hit Feedback (vignette, direction arrows, low-health pulse, rumble).

4. Add it #

Add Hit Feedback:

  • Prefabs get a new Prefab Variant called "Name (Hit Feedback)" in Assets/RareGeometryData/ResponsiveFX/Prefabs. Your original prefab is not changed (a test checks its file stays byte-identical) and still receives your edits and pack updates. Use the variant in your scenes.
  • Scene objects get the component directly. Undo works.

Prefabs with missing scripts are skipped; reimport them and try again.
