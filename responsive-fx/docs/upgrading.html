Upgrading

1.0.0 #

First release. Nothing to do.

Updating Responsive FX later #

  • Import the new version over the old one. Your profiles, settings and Setup Wizard variants live in Assets/RareGeometryData/ResponsiveFX, which updates never touch.
  • Class names, serialized fields, menu paths and settings keys don't change between versions, so your scenes, prefabs and code keep working. Anything that needs a step from you is listed here.
  • If you moved or renamed Responsive FX's folder, that's fine: the tools find Responsive FX's assets by name, not by path.
