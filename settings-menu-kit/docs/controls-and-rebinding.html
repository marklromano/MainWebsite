Controls and rebinding

Without the Input System package #

The menus work with the old Input Manager (keyboard and gamepad navigation, Esc / Start to pause). Mouse and controller sensitivity, invert and vibration are stored settings (Read tier) your input code reads. Key rebinding and controller prompts need the Input System package.

With the Input System package #

Rebinding, controller prompts and the look settings switch on by themselves.

  1. In the kit window's Settings tab, click the Key Bindings setting of your profile copy (or add it from the catalog) to select it.
  2. Set Actions to your Input Action Asset, and Action Maps to the maps players may rebind (for example Player). Optional: Include Actions to show only some actions.
  3. Protected Actions are never offered and never swapped away, so players can't lose menu controls (Submit, Cancel, Navigate, Pause by default).
  4. Look Actions: your look action(s). Mouse / Controller Sensitivity and Invert X / Y are applied to them as processors, live.

What players get:

  • Keyboard & Mouse and Controller tabs, one row per binding, including the parts of WASD-style composites.
  • Choose a row and press the new key or button. Esc or Start cancels; it also gives up after 5 seconds.
  • If the key is already used by another action: "Swap them?" with Swap or Cancel.
  • Reset per row and Reset Bindings for all.
  • Rebinds are part of Apply / Cancel like any setting, and are saved in the settings file.

Controller prompts #

Bindings show button pictures for keyboard and mouse, Xbox, PlayStation and Switch controllers (Kenney Input Prompts, CC0), and switch to the device the player used last. Generic controllers show the stick pictures and text for face buttons. The Glyph Map asset (InputSystem/Content/DefaultGlyphMap) maps control names to sprites: replace any sprite with your own.

Vibration #

ControllerRumble.Play(low, high, seconds, this) vibrates the current gamepad, scaled by the Vibration and Vibration Strength settings.

Pause action #

The Input System front end uses Esc / gamepad Start for pause, or your own action: Setup tab > 3. Pause action.
