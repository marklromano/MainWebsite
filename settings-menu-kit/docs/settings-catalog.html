Docs/Settings & Menu Kit/Features

Settings catalog

A Settings Profile lists the tabs (categories) and settings your menu shows. The kit ships a profile with the full launch catalog; add, remove, reorder or create settings in the kit window's Settings tab.

Tiers: how a setting reaches your game #

Tier Meaning Examples
Auto The kit applies it for you. Nothing to do. Resolution, VSync, quality, volumes, post effects, menu size, language
Connect It drives something in your scene: a component (for example Camera Field Of View Target), a Setting Event Binder with UnityEvents, or your callback. Field of view, your own custom settings
Read The kit stores it; your code reads it when it needs it. Difficulty, camera shake, vibration, hold or toggle

The badge next to each setting in the window shows its tier.

Tabs in the default profile #

Display, Graphics, Audio, Controls, Accessibility, Gameplay. Settings that need something the project doesn't have (a render pipeline, the Input System, a mixer, a second monitor) are hidden automatically, with the reason shown in the catalog. See the Settings reference for every setting.

Add a setting from the catalog #

Settings tab > Catalog: search, then Add. The kit copies the setting next to your profile (your copy, safe from updates). Remove takes it out again. The kit's own profile can't be edited: make an editable copy first (Home tab, step 1).

Create your own setting #

Settings tab > Custom setting (with UnityEvents): choose Toggle, Slider, Whole number or Choice, give it an id (for example gameplay.hints), a label and a tab, and click Create and add to profile. Then select a GameObject and click Add event binder to selection: its UnityEvents fire with the new value whenever the player applies settings.

Needs connection #

The Check tab lists Connect settings that nothing in the open scene listens to yet (for example Field of View without a camera target), each with a one-click fix.
