Troubleshooting and FAQ

The menu doesn't react to the keyboard or gamepad #

  • The scene needs one EventSystem. The front end creates one when the scene has none. The kit window's Check tab finds extra EventSystems and wrong input modules, with a Fix button.
  • Player Settings > Active Input Handling: the kit works with Input Manager (Old), Input System Package (New) or Both. With "New" you need the Input System package installed.

Text is invisible or shows squares #

Import TMP Essential Resources (Window > TextMeshPro > Import TMP Essential Resources). For other alphabets, see Languages.

Music, Sound Effects, Voice or Interface volume doesn't show in Settings #

These need an Audio Mixer: kit window > Home, step 2 (or Setup > Create starter mixer, then Assign). Master Volume works without one.

A graphics setting is missing #

It doesn't apply to your render pipeline or project (for example URP settings in a Built-in project, or Monitor with one screen). The Settings tab's catalog shows why each hidden setting is hidden.

Key Bindings doesn't show #

It needs the Input System package and your Input Action Asset in the Key Bindings setting (Controls and rebinding).

The display change reverted by itself #

That's the 15-second safety countdown: choose Keep to keep a new display mode (Display safety).

Settings were reset #

A damaged settings file is replaced by its backup or the defaults (the damaged copy is kept as settings.json.corrupt). Starting the game with -reset-settings deletes the saved settings on purpose.

My quality settings changed after Play mode #

They shouldn't: the kit puts every quality value back when Play mode ends. If you see a change, please report it with your system info.

Still stuck? #

Kit window > About > Copy system info, then post it with your question:

  • Discord: https://discord.gg/AmpBDxRAKu
  • Bug tracker: https://github.com/romanoassets/RomanoAssetSupport
  • Website: https://romanoassets.github.io
