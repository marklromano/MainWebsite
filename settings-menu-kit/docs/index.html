Docs/Settings & Menu Kit

All In One Game Settings & Menu Kit documentation

A finished game front end: title screen, main menu, settings, pause, loading screen and dialogs, with key rebinding, accessibility, subtitles and three themes, ready for keyboard, mouse and gamepad.

  • Unity 6000.0+
  • Built-in, URP & HDRP
  • No code needed
  • Full C# source
  • Version 1.0.0
Get started

Quick start: five minutes

  1. Import the package. Everything lands in Assets/RomanoAssets/SettingsMenuKit/.
  2. Open Tools > All In One Game Settings & Menu Kit. The Home tab lists the Quick Start steps.
  3. Click each step's button in order: copy the settings profile, create the audio mixer, add the front end, mark your menu scene. Each one gets a check mark.
  4. Press Play. The title screen opens; settings save, apply and come back every time.
