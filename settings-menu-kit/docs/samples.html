Samples

Open any scene in Samples/Scenes and press Play. Each one starts on its menu; New Game starts playing in the same scene, Esc / Start pauses. Every sample uses only what ships with the kit and works with Built-in, URP and HDRP, and with either input system.

Scene Theme What it shows
TryIt Clean The smallest setup: the front end and a spinning cube. Pause freezes time.
Puzzle2D_Clean Clean A "lights out" puzzle (mouse, or arrows and Enter / gamepad). The board size follows Difficulty (a Read setting).
Shooter3D_Tactical Tactical A first-person walk: mouse / controller sensitivity and invert (Read settings), Sprint hold or toggle, Field of View (Connect) and camera shake that follows Reduce Motion. Walk to the orange beacon for subtitles.
CozyAdventure_Storybook Storybook A third-person stroll: walk to Mara for subtitles that follow the subtitle settings.

The sample scripts (Samples/Scripts) are short and commented: copy what you need. Select README (select me) in each scene for its notes.
