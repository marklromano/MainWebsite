Changelog

All notable changes to the All In One Game Settings & Menu Kit are listed here, newest first. The format follows Keep a Changelog, and the kit uses semantic versioning.

[1.0.0] - not released yet (release candidate) #

The first release.

Added #

  • Front end in one prefab (FrontEnd): title screen, main menu, settings, credits, pause menu, loading screen, confirmation dialog, display-change countdown and controller-disconnected prompt. One instance survives scene loads, and there is always exactly one EventSystem.
  • Settings with Apply / Cancel / Reset category / Reset all, an "Unsaved changes" prompt, and a crash-safe settings file (backup and corrupt-file recovery).
  • Audio: master volume (works without a mixer) plus music, sound effects, voice and interface volumes through an optional starter Audio Mixer.
  • Display: resolution, refresh rate and window mode, with a 15-second confirmation that reverts automatically. First launch keeps the game's own display mode.
  • Pause modes: Freeze (time and audio, restored exactly), Overlay only (input lock event) and Custom (events only).
  • Keyboard, mouse and gamepad navigation everywhere, with focus restored when going back.
  • "Clean" theme: colors, Inter font, sizes, 9-sliced sprites, focus highlight, transitions and UI sounds.
  • Editor window with a setup wizard, screen on/off switches, the settings list and validators with one-click fixes.
  • Graphics settings for every render pipeline: quality preset, texture quality, anisotropic filtering, shadow distance and level of detail (each "Preset" or an override), plus MSAA and shadows for the Built-in pipeline.
  • URP settings: render scale, upscaling filter, MSAA, HDR, shadow resolution, post anti-aliasing, brightness, and bloom, motion blur, depth of field, film grain, vignette and chromatic aberration on/off. Your URP assets and volumes are never modified.
  • Display: monitor selection (Windows, shown with two or more monitors), VSync and a frame-rate limit.
  • Camera field of view and camera shake; mouse and controller sensitivity, invert X/Y, vibration and vibration strength.
  • Key rebinding (Input System): keyboard/mouse and controller tabs, WASD-style parts, conflict detection with Swap / Cancel, protected menu controls, reset one or all, saved with your settings.
  • Controller prompts that follow the device in use (keyboard, Xbox, PlayStation, Switch, generic).
  • Custom settings (toggle, slider, whole number, choice) with UnityEvents, created in the editor window; a "Needs connection" list; a searchable catalog of every setting with tier badges.
  • Works without the Input System package (old Input Manager); rebinding and prompts turn on when the package is installed.
  • Three themes: Clean, Tactical (angular, for shooters and action games) and Storybook (warm and round, for fantasy and cozy games), each with a high-contrast version; switch them in the editor window with a live preview.
  • Accessibility: menu size, text size, high contrast, reduce motion, focus outline thickness, hold-or-toggle actions, subtitles (on/off, size, background) with a ready-made subtitle display.
  • Languages: every menu text can be translated with string tables; a language picker; a pseudo-language for testing long translations; optional bridge to Unity's Localization package (reads its string tables and follows its selected locale).
  • Menus fit every screen shape (4:3 to 32:9) and menu size, respect phone/console safe areas, and shrink long texts instead of cutting them off.
  • Tested on Unity 6000.0, 6000.3 and 6000.6, with URP, HDRP and the Built-in pipeline, and without the Input System.
  • Editor window with Home (Quick Start with one-click steps and a guided tour), Setup, Theme, Settings, Check and About (support links with Copy buttons and Copy system info) tabs; an optional one-time welcome window.
  • Four sample scenes: Try It, a 2D puzzle (Clean), a first-person scene (Tactical) and a cozy adventure (Storybook).
  • Full offline manual (Documentation folder) with a generated settings reference.
