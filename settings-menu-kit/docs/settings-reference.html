Docs/Settings & Menu Kit/Reference

Settings reference

Every setting in the default profile, by tab. Tier: Auto = the kit applies it; Connect = it drives something in your scene (a component or your callback); Read = the kit stores it and your code reads it. Ids are what your code uses (SettingsRuntime.Current.GetValue("id")) and what the settings file stores. Settings that need a package or a render pipeline are hidden where they can't work.

This page is generated from the shipped settings.

Display #

Setting Id Tier Default Values What it does
Resolution display.resolution Auto the game's launch value what the player's screen supports Screen resolution.
Refresh Rate display.refresh-rate Auto the game's launch value what the player's screen supports Refresh rate for the chosen resolution (exclusive full screen).
Window Mode display.window-mode Auto the game's launch value Fullscreen, Borderless, Windowed Full screen, borderless or windowed.
Monitor display.monitor Auto the game's launch value what the player's screen supports Which monitor shows the game. Only shown when more than one is connected.
VSync display.vsync Auto the game's launch value On, Off Syncs frames to the monitor to prevent tearing. Off can lower input latency.
Frame Rate Limit display.frame-rate-cap Auto the game's launch value Unlimited, 30 FPS, 60 FPS, 90 FPS, 120 FPS, 144 FPS, 165 FPS, 240 FPS Upper limit for frames per second (when VSync is off).

Texture Quality graphics.texture-quality Auto Preset Preset, Full, Half, Quarter, Eighth Texture resolution. Lower values use less video memory.

Shadow Distance graphics.shadow-distance Auto Preset Preset, 25 m, 50 m, 100 m, 150 m, 200 m How far away shadows are drawn.

Anti-aliasing (MSAA) graphics.msaa-builtin Auto Preset Preset, Off, 2x MSAA, 4x MSAA, 8x MSAA Smooths jagged edges. Higher values cost more performance.
Shadows graphics.shadow-quality-builtin Auto Preset Preset, Off, Hard, Soft Which shadows are drawn.
Shadow Resolution graphics.shadow-resolution-builtin Auto Preset Preset, Low, Medium, High, Very high Sharpness of shadows.
Post Anti-aliasing graphics.post-antialiasing Auto Off Off, FXAA, SMAA, TAA Edge smoothing applied after rendering. TAA is smoothest, FXAA is cheapest.
Brightness graphics.brightness Auto 0.0 -2.0 to 2.0 Overall image brightness (exposure).
Bloom graphics.bloom Auto On On, Off Glow around bright light.
Motion Blur graphics.motion-blur Auto On On, Off Blur on fast camera movement.
Depth of Field graphics.depth-of-field Auto On On, Off Blurs objects out of focus.
Film Grain graphics.film-grain Auto On On, Off Grainy film look.
Vignette graphics.vignette Auto On On, Off Darkened screen edges.
Chromatic Aberration graphics.chromatic-aberration Auto On On, Off Color fringes at the screen edges.
Render Scale graphics.render-scale Auto Preset Preset, 50%, 67%, 75%, 85%, 100%, 125%, 150% Renders at a lower or higher resolution than the screen. Lower is faster.
Upscaling Filter graphics.upscaling Auto Preset Preset, Automatic, Bilinear, Nearest, AMD FSR 1, Spatial-Temporal (STP) How a lower render scale is scaled up to the screen.
Anti-aliasing (MSAA) graphics.msaa Auto Preset Preset, Off, 2x, 4x, 8x Smooths jagged edges. Higher values cost more performance.
HDR Rendering graphics.hdr Auto Preset Preset, On, Off High dynamic range rendering: better lighting, costs some performance.
Shadow Resolution graphics.shadow-resolution Auto Preset Preset, 256, 512, 1024, 2048, 4096 Sharpness of shadows.
