Upgrading

1.0.0 #

The first release. Nothing to do.

How updates work #

  • Your profile, settings, mixer and themes copies live in Assets/AllInOneGameSettingsMenuData (or wherever you saved them), outside the kit's folder: an update never overwrites them.
  • Back up your project (or commit it) before importing an update, then import the new package over the old one.
  • Public API, serialized fields, script GUIDs, menu paths and setting ids are kept across 1.x versions (an automated test checks them against the released version), so your scenes, prefabs and code keep working.
  • A .unitypackage update never deletes files: files the kit no longer needs are left as harmless stubs.
  • The settings file has a version number and is migrated automatically.
  • Each version's changes and any steps to take are listed here and in CHANGELOG.md.
