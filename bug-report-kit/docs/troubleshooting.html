Troubleshooting

Start with Tools > All In One Bug Report Kit > Why Isn't It Working. It checks everything the form needs and offers a one-click fix where there is one.

What you see Why, and what to do
F8 does nothing in the Editor Click the Game view first so it has the keyboard. Check Settings > Include In isn't Never
F8 does nothing in a build The build isn't a Development Build and Include In is Development Builds Only. Tick Development Build, or set Always
"No way to read the key" Active Input Handling is the Input System but the package isn't installed. Install it, or set Both in Player settings
The form has no screenshot markup The uGUI package isn't installed, so the simple form is used. Install uGUI for the full form
A report has no screenshot The game has no graphics device (a headless build) or the tester unticked it
The replay is missing Settings > Replay Seconds is 0, the platform can't read the GPU back, or the tester unticked it
"Discord: not sent" The webhook address is wrong, or the device is offline. The zip is safe on the device, and the kit tries again next start
"http is blocked by Player Settings" Use an https address, or allow http in Player settings (Allow downloads over HTTP)
A stack line in the Inbox isn't blue The script isn't in this project at that path, for example a build from another branch
Go to where the tester was can't find the scene The scene was renamed or isn't in this project
The error badge never shows Settings > Error Badge is off, or the theme's Badge Display is None
My own font looks blurry Use a font with a large enough source size, or raise Text Scale

Known limits: the replay is a few pictures a second, not video. Android and WebGL are checked to compile; they have not yet been run on a phone or in a browser.
