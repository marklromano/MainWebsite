Docs/Bug Report Kit

All In One Bug Report Kit documentation

Testers press one key and you get one file: their words, a marked-up screenshot, a replay of the last seconds, the log with stack traces, system info and your game's state. Plus an in-game console, stats and debug options, and a Report Inbox in the Editor that clicks straight to the broken line.

  • Unity 6000.0+
  • Built-in, URP & HDRP
  • No dependencies
  • Full C# source
  • Version 1.0.1

Free, coming soon to the Asset Store.

Get started

Quick start: five minutes

  1. Import the package. Everything lands in Assets/AllInOneBugReportKit/; your settings go to Assets/AllInOneBugReportKitData/.
  2. Open Tools > All In One Bug Report Kit > Open Demo > Bug Hunt and press Play.
  3. Click Deliver the crate, press F8, write a line, circle the problem and click Save report.
  4. Stop playing and open Tools > All In One Bug Report Kit > Report Inbox. Click the stack line to open the broken script.
