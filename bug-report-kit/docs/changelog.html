Changelog

All notable changes to this kit are documented here, newest first, in Keep a Changelog style.

[1.0.1] - 2026-11-08 #

Safer in existing games, from a second-opinion review of how the kit meets other games' input, pausing, cameras and scenes.

Added #

  • The open and overlay keys do nothing while a Unity UI, TextMeshPro or UI Toolkit text field in your game has focus, and BugReporter.KeysBlocked lets your game block them (a chat box, a rebinding screen). Closing the overlay always works.
  • BugReporter.TesterCamera chooses the camera for "Go to where the tester was". Without it the kit uses the MainCamera, or else the screen camera drawn last, skipping cameras that draw into a texture. Reports name the camera.
  • Reports list every other scene loaded next to the active one, and "Go to where the tester was" opens them too.
  • Settings > Max Attachment Megabytes (50): larger attachments are left out with a note.
  • Why Isn't It Working: an Open the Form Now button while playing, and a warning when Unity's logging is switched off.
  • Docs: "Adding it to your own game", and more Troubleshooting.

Changed #

  • Closing the form keeps a time scale other than 0 that your game set while it was open, and a cursor your game hid or locked meanwhile, instead of undoing them.
  • Very long log lines and stack traces are kept up to 16,000 characters each; the overlay shows up to 12,000 and Copy copies all of it.
  • Game state providers on destroyed objects are dropped instead of failing.
  • The first console command scan reads only assemblies that use the kit.

[1.0.0] - 2026-11-07 #

Added #

  • Report form (uGUI, with a simple fallback when uGUI isn't installed): screenshot taken before the form, markup, category, severity, steps filled in from recent events, and a preview of every part with tick boxes.
  • Each report is one zip: an HTML page, JSON, screenshot, replay of the last seconds, Console log with stack traces, recent events, system info, game state and attachments.
  • Optional Discord and HTTP destinations, off by default, with a retry queue.
  • Debug overlay: console with search, level filters, collapse and Copy All; commands; stats strip and frame time graph; debug options from attributes or a component, with no UI code; error badge; pinning.
  • Report Inbox in the Editor: clickable stack traces, Go to where the tester was, statuses, notes, search, filters and CSV export.
  • Make it yours: four themes, theme and text table assets, text size, fonts, images, corners and sides, safe areas, Display as for status messages, gamepad focus.
  • Development builds only by default: release builds leave out the code that starts the kit, its Unity UI screens, its input code and its settings.
  • Setup Wizard, Why Isn't It Working, Help and Support, and two demo scenes.
