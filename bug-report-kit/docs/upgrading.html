Upgrading

Updating the kit #

  1. Back up your project or commit it.
  2. Import the new version from the Package Manager (My Assets). Import everything it offers.
  3. If Unity reports errors after importing, delete the AllInOneBugReportKit folder and import again: files the new version removed are then gone too.

Your settings, themes, text tables, Inbox statuses and notes live in Assets/AllInOneBugReportKitData, outside the kit, so an update never changes them.

You can move or rename the kit's folder. It finds its own files wherever they are.

What changed in each version #

1.0.1 #

Nothing to do. New: the kit's keys are ignored while your game's text fields have focus, BugReporter.KeysBlocked, BugReporter.TesterCamera, Settings > Max Attachment Megabytes, and the "Adding it to your own game" page. Closing the form now keeps a slow-motion time scale your game set while it was open, and a cursor your game hid or locked.

1.0.0 #

The first release. Nothing to do.

The full list of changes is in CHANGELOG.md in the kit's folder.
