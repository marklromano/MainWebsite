Docs/Bug Report Kit/Reference

Settings

Open them with Tools > All In One Bug Report Kit > Settings. The first time, this makes BugReportSettings.asset in Assets/AllInOneBugReportKitData. That folder is yours: it sits outside the kit, so updating the kit never touches it. Every setting has a tooltip.

Builds #

Setting Default What it does
Include In Development Builds Only Which builds contain the kit. See Builds and privacy

Look #

Setting Default What it does
Theme empty Your own theme asset. Empty uses the preset below
Theme Preset Studio Studio, Daylight, Terminal or High Contrast
Text Table empty Your own words for everything testers read. Empty uses the kit's English

More in Make it yours.

Opening the form #

Setting Default What it does
Open Key F8 Opens the report form
Show On Screen Button off A small Report a Bug button, for touch screens and gamepads
Touch Gestures on Three-finger tap opens or closes the overlay, four-finger tap opens the form
Pause While Open on Stops game time while the form is open and frees the mouse cursor

Debug overlay #

Setting Default What it does
Enable Overlay on The console, stats strip and debug options
Overlay Key the key above Tab Opens and closes the overlay
Stats Strip With Overlay When frame rate, frame time and memory show: never, with the overlay, or always
Error Badge on While the overlay is closed, a small badge counts new warnings and errors
Enable Commands on Lets testers type commands in the console

More in Debug overlay.

Choices in the form #

Setting Default What it does
Categories Gameplay, Visual, Audio, UI, Performance, Other What a tester can pick. An empty list hides the choice
Severities Minor, Major, Blocker Same, for severity

What is captured #

Setting Default What it does
Log Lines 1000 How many Console lines are kept in memory
Breadcrumb Seconds 60 How far back the recent events go
Max Attachment Megabytes 50 Attachments larger than this are left out, with a note in the report
Default Parts All Parts ticked when the form opens. Testers can still untick them
Replay Seconds 5 How many seconds before the report the replay covers. 0 turns it off
Replay Frames Per Second 2 More is smoother and uses more memory
Hide User Name on Replaces the computer's user name in logs and game state
Privacy Note empty The line in the form saying where reports go. Empty writes one that matches your destinations
Auto Report Exceptions off Saves a report by itself the first time each different exception happens, at most 5 a session

Optional destinations #

The zip is always saved on the device. These are off until you switch them on.

Setting Default What it does
Send To Discord, Discord Webhook Url off, empty Also posts each report to a Discord channel. Use a private test channel
Send To Http, Http Url off, empty Also sends each report to your server as a form POST: a report zip plus id, category, severity and summary

Why Isn't It Working (same menu) checks these settings against your project and says in plain words what to change.
