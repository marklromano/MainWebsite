Quick Start

The kit works the moment it's imported. No setup is needed for the first report.

  1. Open Tools > All In One Bug Report Kit > Open Demo > Bug Hunt and press Play.
  2. Press Deliver the crate. The game throws an error and the crate falls through the floor.
  1. Press F8. The form opens with a screenshot taken just before it, and the steps already filled in.
  2. Type what happened, draw a circle round the crate, and press Save report.
  1. Stop playing. Open Tools > All In One Bug Report Kit > Report Inbox and pick This PC's Reports.
  2. Click the blue BugHuntDemo.cs link under the error: your code editor opens on the broken line.
  3. Press Go to where the tester was: the Scene view jumps to the tester's camera.

In your own game #

Press F8 while playing any of your scenes. That's all. To make it yours:

  • Tools > All In One Bug Report Kit > Setup Wizard creates the settings, adds your game state to reports and points you to the rest.
  • Press the key above Tab while playing for the debug console, stats and options.
  • In a Development Build the kit is there; in a release build it isn't. See Builds and privacy.

Where reports go #

On the tester's device, in the game's persistent data folder under BugReports. Each one is a single zip with report.html (opens in any browser), report.json, the screenshot, the replay pictures and the log. Testers send you the zip; you open it in the Report Inbox, or just open the html.
